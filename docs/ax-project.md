# 내 AX 프로젝트

**AX(AI 전환) 프로젝트**는 내 업무 하나를 골라 6일 동안 AI로 바꾸는 계획입니다.
매일 오후 대표 예제(한빛정밀)로 익힌 방법을 7교시에 내 일에 옮기고, 마지막 날 도입 기획서와 ROI를 들고 3분 발표합니다.

!!! quote "AI 도입은 구매가 아니라 과업 선정이다"
    도구를 고르기 전에 **어떤 일을, 어떤 데이터로, 무엇으로 성공을 재는가**를 먼저 정합니다.
    AI 프로젝트 실패의 주원인으로 꼽히는 것도 도구가 아니라 **문제 정의를 잘못 이해한 것과 데이터 부족**입니다(RAND 2024 — [레퍼런스](references.md#d1-41)).

## Day1 — AX 문제 정의 캔버스 7칸 {#canvas}

[Lab3](day1/lab3.md)에서 템플릿의 `07_내AX프로젝트` 시트(또는 `ax_canvas_template.md`, [Day1 파일 받기](day1/index.md#files))에 채웁니다.

|---|---|---|---|
| 1 | **업무** | 누가 · 무엇을 | "채권 담당자가 매주 연체 바이어 목록을 만든다" / "채권 관리" |
| 2 | **현재 방식** | 시간 · 빈도 | "엑셀 3개를 합쳐 주 1회, 2시간" / "수작업" |
| 3 | **불편 · 위험** | 무엇을 놓치면 비싼가 | "연체를 늦게 알아, 이미 연체 중인 바이어에 또 선적한다 → 못 받을 돈이 커진다" / "불편하다" |
| 4 | **데이터** | 무엇이 · 어디에 · 민감도 | "ERP 미수금 원장(사내 서버, 거래처명 포함 → 익명화 필요)" / "회사 데이터" |
| 5 | **AI가 할 일** | 읽기 / 구조화 / 판단 보조 / 보고 / 자동화 | "원장을 읽어 연체 구간별 목록 초안 만들기(구조화·보고)" / "AI가 알아서" |
| 6 | **사람이 할 결정** | 승인 지점 | "선적 보류 여부는 팀장이 목록을 보고 결정" / (빈칸) |
| 7 | **성공 지표** | 전 → 후 | "주 2시간 → 20분, 연체 인지 D+15 → D+3" / "업무가 편해진다" |

!!! warning "5번과 6번이 둘 다 채워져 있나요?"
    AI가 할 일만 있고 **사람의 결정**이 없으면, 그것은 위험한 자동화입니다. 결정과 승인은 사람이 합니다.

## 과업 선정 3기준 {#criteria}

후보 과업이 여러 개라면 각각 세 기준에 **1–5점**을 매기고, 점수마다 **근거 한 줄**을 씁니다. 점수에 정답은 없습니다.

| 기준 | 묻는 것 | 1점 | 5점 |
|---|---|---|---|
| **즉시 효과** | 지금 바로 시간이 줄어드는가? | 효과가 몇 달 뒤 | 다음 주부터 바로 |
| **KPI 직결** | 회사가 이미 재는 숫자와 연결되는가? | 잴 방법이 없다 | DSO·연체율·처리시간 같은 기존 지표가 바로 움직인다 |
| **추가 인프라 불필요** | 새 시스템 없이 지금 도구로 되는가? | 새 시스템·개발·데이터 연동 필요 | 지금 쓰는 AI·엑셀로 된다 |

세 점수가 모두 높은 과업이 **첫 프로젝트 후보**입니다. 예를 들어 '바이어 연차보고서 1차 검토'는 오늘 Lab1처럼 지금 도구로 바로 되지만,
'30일 연체 예측'은 데이터 준비와 평가가 더 필요합니다(Day3에서 다룹니다).

## 옆 사람 검증 질문 {#peer-check}

Lab3 마지막 10분, 옆 사람과 캔버스를 바꿔 보고 **딱 하나**만 묻습니다.

> **"무엇을 놓치면 비싼가?"**

시간이 남으면 이어서 묻습니다.

- 사람이 승인하는 지점은 어디인가?
- 성공을 어떤 숫자로 재나? 지금(전) 그 숫자는 얼마인가?
- 그 데이터는 어디에 있고, AI에 넣어도 되는가(민감도)?
- 새 시스템 없이 다음 주에 시작할 수 있나?

피드백은 **칭찬 → 보완 → 생각 확장** 순서로 짧게 합니다.
예: "불편·위험 칸이 구체적이라 좋습니다 → 성공 지표에 '전' 숫자가 비어 있네요 → 사람 승인 지점을 하나 더 둔다면 어디일까요?"

## 8교시 쇼케이스 — 내 문제 1장, 3분 {#showcase}

| 규칙 | 내용 |
|---|---|
| 발표 | 팀별 대표 1명(또는 팀원 전원 30초씩) · 캔버스 1장 · 팀당 3분(발표 2분 + 질문·피드백 1분) |
| 질문 | 옆 팀이 하나만 묻는다 — **"무엇을 놓치면 가장 비싼가?"** |
| 피드백 | 강사 한 줄(칭찬 → 보완 → 생각 확장) |
| 시간 | 5팀 × 3분 = 15분 → 17:40 미닛카드 |

발표 화면에 회사 실명·담당자 이름이 보이면 발표 전에 가립니다.
