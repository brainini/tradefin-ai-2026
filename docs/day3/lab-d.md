## 작업 안내서란? {#guide}

이 실습의 프롬프트는 **두 줄**입니다 — 첫 줄은 **목적**(무엇을 위해), 둘째 줄은 **할 일**. 화면 구성 · 설정 숫자 · HTML 규칙 · 커밋 규칙 같은 긴 규칙은 AI가 읽는 **작업 안내서** `labs/day3/lab-d/lab_d_guide.md`에 들어 있습니다. 1일차의 `CLAUDE.md`처럼 **긴 규칙은 파일에 두고, 프롬프트는 목적만** 말한 뒤 "안내서의 「3. 첫 화면 v1」대로"처럼 절 이름으로 가리킵니다.

안내서는 사람이 읽어도 되는 한국어입니다. 궁금하면 VS Code에서 열어 봐도 됩니다(++ctrl+shift+v++ 미리보기) — 받은 원본이라 고치지는 않습니다. 절은 0 늘 지킬 것 · 1 메모와 표 훑기 · 2 디자인 주문서 · 3 첫 화면 v1 · 4 결과 페이지 규칙 · 5 커밋 규칙 · 6 2부 옵션 — 스타일 · 7 2부 옵션 — 기능 · 8 AI 티 지우기 · 9 게시 · 10 숫자가 다를 때 · 11 채팅 경로입니다.

단계마다 이 순서로 읽습니다 — **이 단계의 목적**(한 줄) → 프롬프트(복사 단추 :material-content-copy:) → **확인할 것**(기대값). `{중괄호}` 자리가 있으면 그것만 바꿔 보냅니다(중괄호 기호도 지웁니다).

## 잘 만드는 법 — 레퍼런스 · 주문서 · 'AI 티' {#craft}

AI에게 "예쁘게 만들어 줘"라고만 하면 AI가 가장 많이 본 화면이 나옵니다 — 보라색 그라데이션, 이모지 아이콘, 그림자 진 카드. 대표님이 말한 바로 그 'AI 티'입니다. 오늘은 그림 실력이 아니라 **순서**로 이깁니다.

1. 남의 좋은 화면을 찾는다 — **레퍼런스**(D-1 · 02)
2. 무엇을 따라 할지 글로 정한다 — **디자인 주문서** `design.md`(D-1 · 03)
3. AI에게 그 글 안에서만 만들게 한다 — "토큰 밖 값 금지"(D-1 · 04부터)
4. 내 화면을 캡처해 레퍼런스와 다시 견준다 — **비평**(D-2 · 03)

#### 2 · 고르는 눈 {#pick}

마음에 드는 화면이 많으면 네 가지로 거릅니다.

- **조용하다** — 정보가 많은데도 선 · 상자 · 색이 적고 여백이 넉넉합니다
- **주인공이 하나다** — 눈이 제일 먼저 가는 곳이 한 군데(오늘은 'C등급 몇 곳 · 얼마')
- **숫자가 크고 설명이 작다** — 숫자는 크고 진하게, 설명은 작고 흐리게
- **색은 의미에만** — 빨강은 위험일 때만, 나머지는 회색 계열

두 장은 쓸모를 나눠 고릅니다 — 한 장은 **전체 배치**(넓은 화면), 한 장은 **KPI 카드 · 표 · 휴대폰 화면** 같은 부분. 사진 · 일러스트가 주인공인 화면은 고르지 않습니다 — 우리 화면의 주인공은 숫자입니다.

#### 3 · AI에게 주는 법 {#brief}

1. **캡처를 보여 주고 따라 할 것을 좁힌다** — "구조 · 간격 · 글자 위계만, 색과 내용은 우리 것"
2. **토큰부터 정한다** — 토큰은 화면에 쓸 색 · 글꼴 · 글자 크기 · 간격 · 모서리 · 그림자를 미리 정해 이름을 붙인 값. `design.md`에 표로 정해 두고 그다음부터 "토큰 밖 값 금지"
3. **방향은 사람이 고른다** — 한 번에 정답을 바라지 않고, 스타일을 고르거나 3안을 견줘 고릅니다(2부)
4. **스크린샷으로 비평하게 한다** — AI는 자기가 쓴 코드만 알고 화면은 못 봅니다. 캡처를 보여 주고 "디자이너처럼 아쉬운 점 5개"
5. **한 번에 하나만 고친다** — 다섯 개를 한꺼번에 고치면 무엇이 좋아졌는지(또는 망가졌는지) 모릅니다

#### 4 · 'AI 티' 금지 목록 {#no-ai-look}

AI가 '예쁘게'를 들으면 먼저 꺼내는 것들입니다. 같은 표가 안내서 「2. 디자인 주문서」에 있어서 AI가 주문서에 옮기고 스스로 피합니다.

| 금지 | 대신 |
|---|---|
| 보라 · 파랑 그라데이션 | 흰색 · 연회색 바탕 + 강조 1색 |
| 이모지 아이콘 | 글자 라벨, 꼭 필요하면 선 아이콘(SVG) |
| 모든 카드에 그림자 | 1px 테두리나 바탕색 차이 |
| 유리(blur) 효과 남발 | 불투명한 면 |
| 가운데 정렬 일색 | 글은 왼쪽, 숫자는 오른쪽 정렬 |
| 'Welcome back!' 같은 빈말 | 기준일 · 데이터 범위처럼 쓸모 있는 한 줄 |
| 무지개색 차트 | 회색 + 뜻이 있는 1–2색(등급 색) |
| 지나치게 둥근 모서리 | 4–8px |
| 의미 없는 장식 그림 | 빈칸(여백) |
| 영어 더미 글 | 우리말 진짜 문장 |

#### 5 · 데이터 화면 기본기 {#data-basics}

- 숫자는 **오른쪽 정렬 · 천 단위 쉼표 · 단위**($ · 곳 · %), 그리고 **한 줄**(숫자 가운데서 줄을 바꾸지 않는다)
- 등급 색은 **고정**(S 초록 → C 빨강)하고 **글자 라벨**을 함께 — 색만으로 말하지 않습니다(색을 구별하기 어려운 사람 · 흑백 인쇄)
- KPI는 **4개 이하**, 표는 **상위 10** — 나머지는 상세 패널이나 '전체 보기'로
- 글자와 바탕의 대비 **4.5 : 1 이상** — Adobe Color의 대비 확인으로 잽니다
- 휴대폰에서는 **표 대신 카드**(바이어 한 곳 = 카드 한 장)

#### 6 · 결과 페이지 한 장의 규칙 {#page-rules}

`buyer_board.html`은 내 PC에서 더블클릭해도, Claude 아티팩트로 게시해도 **같은 화면**이어야 합니다. 자세한 규칙은 안내서 「4. 결과 페이지 규칙」에 있고 AI가 지킵니다. 사람은 넷만 기억합니다.

- **파일 하나** — 숫자는 `scripts/board_page.py`가 CSV에서 계산해 넣습니다. HTML을 손으로 고치지 않습니다
- **바깥은 두 군데만** — 스크립트는 `cdnjs.cloudflare.com`, 글꼴은 Google Fonts. 그 밖의 외부 요청은 없습니다
- **휴대폰 폭(390px)에서도** 가로 스크롤 없이 · **이모지 없음**
- **숫자는 코드로 계산한 값만** — AI가 끝에 주는 '확인할 것 3줄'을 화면과 대조하는 것은 사람입니다

2. **D-1 · 02–03** — 레퍼런스 사냥은 같습니다. 캡처 2장을 첨부해 d2를 보내고, 답의 `design.md`를 내려받습니다.
3. **D-1 · 04** — d3를 그대로 보냅니다. 계획을 먼저 보여 주면 읽고 "좋아, 진행해". 보드가 오른쪽에 아티팩트로 뜹니다.

## 막힐 때 {#troubleshooting}

단계 안의 '막히면'에 없는 것만 모았습니다.

| 증상 | 이렇게 해 보세요 |
|---|---|
| 허락 창이 계속 뜬다 | 정상입니다. 무엇을 · 어디에를 읽고 `1 Yes`. 모르는 명령이면 `No` 하고 "이 명령이 뭐 하는 거야?"라고 묻습니다. `2 … for this project`는 쓰지 않습니다 |
| AI가 '안내서를 찾을 수 없다' · '「3」이 무엇인지 모른다'고 한다 | `labs/day3/lab-d/lab_d_guide.md`가 있는지 봅니다(없으면 `uv run python tools/get_day_files.py 3`). 입력창의 `@labs/day3/lab-d/lab_d_guide.md`가 칩으로 붙었는지도 봅니다 |
| AI가 시키지 않은 다음 단계(2부 옵션)까지 만들었다 | "안내서 「0」대로 프롬프트가 가리킨 절만 — 방금 더한 ○○는 되돌려"라고 보냅니다 |
| 한글이 투박한 기본 글꼴로 보인다 | 인터넷 연결을 봅니다(글꼴은 Google Fonts에서 받습니다). 회사망이 막으면 글꼴만 다르고 숫자는 같으니 그대로 둡니다 |
| 고칠수록 디자인이 조금씩 흐트러진다 | "board_page.py의 색 · 크기 · 간격 중 design.md 토큰에 없는 값을 표로 보여 주고 토큰으로 바꿔"라고 보냅니다 |
| AI가 HTML 파일을 직접 고쳤다 | "HTML은 손으로 고치지 말고 board_page.py를 고쳐 다시 만들어" — 다음에 스크립트를 돌리면 손으로 고친 곳이 사라집니다 |
| Codespaces라 HTML을 브라우저로 못 연다 | 탐색기에서 파일 오른쪽 클릭 → **Download**로 내 PC에 받아 엽니다 |
| 화면 숫자가 이 쪽의 값과 다르다 | [D-1 · 04](#d1-4)의 '숫자가 위 값과 달라요' 프롬프트로 어디서 갈렸는지부터 묻습니다 |
| 원본 `buyer_board.csv`를 AI가 고친 것 같다 | 받은 파일이라 git이 지켜 주지 않습니다. 이름을 바꿔 두고(예: `buyer_board_old.csv`) `uv run python tools/get_day_files.py 3`을 다시 실행하면 원본을 새로 받습니다 |
| `git status`에 `labs/day3/lab-d/` · `refs/`의 png가 보인다 | 받은 원본과 캡처가 '추적하지 않는 파일'로 보이는 것입니다. 커밋에 고르지 않으면 됩니다(지우지 않습니다) |
| 사용 한도에 걸렸다 | 안내의 풀리는 시각을 확인하고, 그동안은 짝의 화면이나 채팅 경로로 진행합니다 → [FAQ](../faq.md#q-usage-limit) |
