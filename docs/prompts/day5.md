## 이 쪽에 대해 {#about}

- 이 쪽은 저장소의 `labs/day5/prompts.md`를 그대로 보여 줍니다. 같은 프롬프트가 [실습 A](../day5/lab-a.md) · [실습 B](../day5/lab-b.md)의 단계 카드마다 들어 있습니다. 오후 슬라이드의 실습 장에 적힌 번호(P5-A2 · P5-A3 · P5-B1 · P5-B2 · P5-B4)는 여기와 **같고**, P5-A1 · P5-A4는 슬라이드 단계에 번호 없이 나오고 P5-B3 · P5-B5는 강사가 말로 안내하는 프롬프트라, 이 네 번호는 이 쪽에서 붙였습니다. P5-A1은 슬라이드 49의 지시문을 프로젝트용으로 고친 글입니다 — [다른 곳](#p5-a1). 번호가 없는 [도움 문장](#helpers)은 옮겨 적기 · 대조 같은 손일을 줄이려고 사이트에서 더한 문장입니다. 오전 시연 다섯 건의 프롬프트는 슬라이드에 핵심만 보였고 여기에 전문이 있습니다.
- 빈칸 값(오류 전문 · 고른 기능 · 안 맞는 숫자 · 질문 목록 · 고친 칸 · 내 주소)은 위쪽 [빈칸 값 표](#values)에 있습니다.
- **모델은 이름보다 계층으로**: 서비스마다 모델 이름과 고르는 메뉴가 다르고 자주 바뀝니다. 결과가 이상하면 같은 프롬프트를 더 큰 모델(생각을 더 하는 모델)로 바꿔 비교해 보세요. 무료 계정은 사용량이 적을 수 있고, Claude Code는 유료 플랜이 필요합니다.
- **데이터 위생**: 이 프롬프트는 가상(합성) 데이터용입니다. 회사 실데이터 · 개인정보는 어떤 AI 도구에도 넣지 않습니다 — 익명화본도. 자사 숫자가 필요하면 [익명화 체크리스트](../setup.md#byod)를 통과한 값만, 내 PC에서 쓰거나 개인 기획서의 비공개 폼으로 냅니다.
- 앱의 비밀값(Secrets)은 코드 · 저장소 · 채팅창에 쓰지 않고 배포 화면의 비밀값 칸에만 둡니다. 오늘은 비워 두면 모의 모드로 끝까지 돕니다 → [기초 F5](../foundations/f5.md).

## 수업판 실습 C · D 프롬프트 {#class}

10/20 실제 수업(수업판)의 실습 C · D에서 쓰는 프롬프트입니다. 저장소의 `labs/day5/prompts_c.md` · `labs/day5/prompts_d.md`를 그대로 보여 주고, 같은 글이 [실습 C](../day5/lab-c.md) · [실습 D](../day5/lab-d.md)의 단계 카드마다 들어 있습니다. 위의 실습 A · B 프롬프트는 인쇄본 자료(참고)로 그대로 둡니다.

- [실습 C · 사라지는 수첩 미스터리](#class-c) · [실습 D · 독촉 메일 대작전](#class-d) — 둘 다 어제 만든 웹 저장소 `tradefin-web-T{조}-{번호}`에서 보냅니다.
- 비밀번호 · 연결 주소 · 승인 코드는 어떤 프롬프트에도 쓰지 않습니다. `.env`는 내가 직접 채웁니다.
- 2부 '자유 퀘스트'에는 정해진 답이 없습니다. 하고 싶은 것 한 줄(몰라도 됨)을 넣으면 AI가 재미있는 방향 3개를 먼저 제안하고, 고르면 계획 3줄 → 승인 → 만들기로 이어집니다.
