# 5일차. AI 금융 에이전트 및 채권 관리 종합 제어 대시보드 구축

**10/20(화) 09:00–17:50** · 대전 · 강사 한태구 · AI로 일하는 법 — 웹 · API · 실시간 연동 · DB · RAG · 에이전트

!!! abstract "오늘 하루 한 줄 — 어제까지 만든 등급 · 한도 · 경보를 화면과 에이전트로 서비스한다"
    오전에는 데이터가 내 화면까지 오는 길(웹 · API · 실시간 연동), 웹앱을 AI와 함께 만들어 내보내는 순서, 파일에서 DB로 옮기는 법, 근거를 찾아 인용하며 답하는 RAG를 **시연 네 건**으로 봅니다.
    오후에는 그 시연을 **작게, 그리고 조금 다르게** 모두가 내 저장소에서 직접 해 봅니다. 하루가 끝나면 **인용 · 기권하는 규정 챗봇과 F1@K 평가표, 실시간 환율 타일과 내가 고친 톤 규칙이 든 채권 상황판(내 주소로 배포), 승인 기록 DB, 내일의 팀 저장소**가 남습니다. 저녁 8교시에는 AI 에이전트를 배우고 **시연 5**로 독촉 에이전트가 도구 · 승인 · 추적으로 일하는 모습을 봅니다.

!!! note "Claude Code는 유료 구독이 필요합니다"
    Claude Code는 Pro 이상 구독이나 API(Console) 계정으로 로그인합니다. 무료(Free) 플랜으로는 쓸 수 없습니다. 설치가 막힌 PC는 내 저장소에서 **Codespaces**를, 계정이 없으면 **채팅 경로**로 같은 실습을 합니다 → [실습 A 채팅 경로](lab-a.md#chat-path) · [실습 B 채팅 경로](lab-b.md#chat-path).

!!! tip "패키지가 없다고 하면"
    오늘 새로 필요한 패키지는 **`pypdf`**(PDF 읽기) · **`rank-bm25`**(검색)입니다(실습 A3 · A4). Claude Code가 `uv add pypdf rank-bm25`를 하겠다고 먼저 알려 주면 읽고 승인하고, 직접 한다면 터미널에서 같은 명령을 칩니다. `pyproject.toml`과 `uv.lock`이 함께 바뀌니 커밋에 포함합니다. 대시보드 패키지는 `uv sync --group dash`로 받습니다 — 그룹 없이 `uv sync`만 다시 하면 streamlit이 지워지니 이 줄 그대로 칩니다.

## 파일 받기 {#files}

**내 저장소에서 명령 하나**면 됩니다. 규정 PDF · 골든셋 · 질문 목록 · 평가 시트 · 요구사항 카드 · 톤 표 · 기록 양식은 **이미 저장소(과정 템플릿)에 들어 있고**, 08:30에 새로 올라오는 것은 시작 파일 `d5_start.csv` 하나입니다. 명령은 없는 파일을 같은 경로로 받고, 고쳐 쓸 파일은 `workbench/day5/data/`에 **작업 사본**도 만들어 줍니다.

```text
uv run python tools/get_day_files.py 5
```

| 시각 | 올라오는 것 |
|---|---|
| **08:30** | 시작 파일 `data/checkpoints/d5_start.csv` (앞선 날의 `d3_start_scoring.csv` · `d4_*.csv` · `models/`가 내 저장소에 없으면 같이 받습니다 — 앱 ② · ③이 읽습니다) |
| **18:00** | 슬라이드 PDF |

- 08:30 전에는 "공개 전"이라고 알려 주고 아무것도 바꾸지 않습니다. 시각이 지난 뒤 같은 명령을 다시 실행합니다.
- **원본(`data/`, `labs/`, `rag/`)은 고치지 않습니다.** 요구사항 카드 · 톤 표처럼 고쳐 쓸 파일은 `workbench/day5/data/`의 작업 사본에서 합니다. 코드는 `scripts/`에, 결과는 `workbench/day5/outputs/`에 둡니다.
- 막히면 아래 표에서 직접 받습니다. 저장소 없이 채팅 경로로 하는 사람은 이 방법을 씁니다.

1. 아래 표 맨 위 **`day5_files.zip`** 줄의 **받기**를 누릅니다(08:30 이후). 그 시각까지 공개된 오늘 파일이 전부 들어 있습니다.
2. 파일 탐색기(Mac: Finder)에서 **다운로드** 폴더를 엽니다.
3. 받은 zip 파일을 마우스 오른쪽 버튼으로 누르고 **모두 압축 풀기** → **압축 풀기**를 누릅니다. (Mac: zip 파일을 더블클릭)
4. 압축이 풀린 창에 보이는 **`D5`** 폴더를 바탕화면으로 끌어다 놓습니다.

- 오늘 쓰는 데이터는 모두 **(가상) 한빛정밀(주)의 합성 데이터**이거나 **공개 데이터**입니다. 한빛정밀(주)과 바이어 · 인보이스 · 연체 · 등급 · 한도 · 가상 규정(`rag/corpus/hanbit_credit_policy.pdf` · `.md`)은 교육용 가상이며 실존 기업 · 기관과 무관하고, 숫자는 실제 거래 기록이 아닙니다. 투자 · 여신 · 보험 판단 자료가 아닙니다.
- 합성 데이터와 문서는 CC BY 4.0, 코드는 MIT입니다. 저장소의 환율 파일(`fx_krw_daily.csv` 등)은 미국 연준 H.10 환율(FRED 제공)로 'Public Domain: Citation Requested'이며 인용 방법은 저장소의 `data/external/ATTRIBUTION.md`에 있습니다. 라이선스 전문은 저장소의 `LICENSE-DATA.md` · `NOTICE.md`에 있습니다.
- 시연 1과 실습 B3의 **실시간 환율**은 키 없이 쓰는 공개 환율 서비스(`api.frankfurter.dev`)를 부릅니다. 받은 응답은 시연 · 실습용으로만 쓰고, 응답 원문을 저장한 파일은 저장소에 커밋하지 않습니다. 환율은 날마다(제공처에 따라 하루 중에도) 달라지므로 화면에는 **환율 날짜 · 받은 시각 · 제공처**를 함께 적습니다. 환율 숫자는 거래용이 아닙니다.
- 보험 약관 본문은 이 저장소에 없습니다(재배포하지 않습니다). 슬라이드와 규정이 말하는 약관 관련 내용은 개념 설명이고, 실제 조항은 각자 공식 자료와 담당 부서로 확인합니다. 약관 PDF를 받아 쓰려면(실습 A7 ④ 심화) 파일 이름에 `약관`을 넣어 `rag/corpus/`에 두면 커밋에서 자동으로 빠집니다 → [rag/corpus/README.md](https://github.com/brainini/tradefin-ai-2026/blob/main/rag/corpus/README.md).
- 열 하나하나의 뜻은 [데이터 → 시작 파일의 주요 열](../data.md#checkpoint-columns)과 `data/data_dictionary.xlsx`의 `columns` 시트에 있습니다.
- **오늘 파일은 합성 데이터라 ChatGPT · Claude 같은 AI 도구에 올리거나 붙여 넣어도 됩니다.** 다만 **회사 실데이터 · 개인정보는 어떤 AI 도구에도 넣지 않습니다 — 익명화본도.** AI 서비스의 '모델 개선(학습)' 설정은 끄고 시작하고([사전 준비 — AI 학습 설정 끄기](../setup.md#ai-training)), 내 저장소는 공개이므로 **키 · 비밀번호 · 회사 자료는 커밋하지 않습니다.** 배포하는 앱의 비밀값은 Streamlit **Secrets** 칸에만 두고, 오늘은 비워 두면 모의 모드로 끝까지 돕니다.
- 오늘 앱의 독촉 메일 예제의 회사 · 주소는 모두 가상(`buyer+B017@example.com` 꼴)이고, **실제로 나가는 메일은 0통**입니다 — 초안과 승인 기록만 남깁니다.
- 6일차 도입 기획서에 쓸 자사 사례는 회사의 반출 정책을 먼저 확인하고, 실명 · 회사 이름은 익명화합니다.

- **제출 = push · PR**입니다. PR 링크와 앱 주소를 **제출 칸**(제출 폼)에 붙여 넣으면 강사가 확인합니다. 제출 폼 링크는 당일 [사이트 홈](../index.md) 공지와 오픈채팅에 있습니다.
- **병합(merge)은 내가 GitHub 화면에서 직접** 누릅니다. 배포용으로 main에 병합된 코드를 Community Cloud가 읽습니다.
- 점검 기준은 **'파일이 있다'가 아니라 검증한 흔적**입니다 — 테스트 통과 · 숫자 대조 · 화면에서 Then 확인 같은 것들입니다.
- PR 본문 · 커밋 메시지 · 보고서에 **회사 이름 · 실명 · 실제 숫자를 쓰지 않습니다.** 저장소가 공개입니다.

## 함께하는 규칙 {#rules}

- **1:1 순회**: 강사가 실습 동안 한 분씩 2–3분 확인합니다. 막히면 손을 들거나 빨간 표시를 올립니다. 막히면 ① 그 AI에게 오류 전문 ② 짝 ③ 손들기 순서로, **20분 넘게 막히면 강사 완성본**으로 합류합니다.
- **짝과 서로 PR을 리뷰**: 서로의 PR에 코멘트 하나씩. 보는 것은 다섯 가지 — 바뀐 파일 · 커밋 메시지의 '왜' · 실데이터가 없는지 · 키가 없는지 · 한 줄 코멘트.
- **숫자보다 절차**: AI가 고른 토큰 방식 · 검색 순서에 따라 F1@K의 끝자리는 사람마다 조금씩 다릅니다. 옆 사람과 숫자가 달라도 **정의대로 계산했다면 정상**입니다. 이상하면 [안 맞을 때](../prompts/day5.md#mismatch)를 먼저 묻습니다.
- **요구사항을 먼저, 한 번에 하나**: 프롬프트는 하나 보내고 결과를 읽은 뒤 다음으로 갑니다. 새 일은 새 대화에서 시작합니다. 이미 도는 앱에 기능을 더할 때는 "기존 것은 바꾸지 말 것 · 새 패키지 금지 · 테스트 통과"를 매번 적습니다.
- **허락 창은 읽고 승인**: 무엇을 · 어디에 · 지우는지 세 가지를 읽고 `1 Yes`. 파일 삭제 · 강제 push · `git reset --hard`는 거절합니다. **병합은 Claude Code에게 시키지 않고 내가 직접** 누릅니다.
- **키는 금고에**: Secrets에만 두고 저장소 · 채팅창 · 단체방에 붙이지 않습니다. 노출되면 폐기와 재발급이 먼저입니다.
- **현장 이야기를 들려 주세요**: 실습하다가 "우리 회사에서는 이렇게 한다"는 이야기가 나오면 말씀해 주세요 — 6일차 도입 기획의 재료가 됩니다.
