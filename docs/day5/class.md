# 저장하고 · 지키고 · 감각과 AI를 붙이는 웹앱

**어제의 웹앱이 기억하고, 지키고, 듣고 말하고 — AI 초안은 사람 승인 뒤에만.** 오전은 이론만 합니다(시연 없음) — 데이터를 저장하는 웹앱(DB · Supabase · Prisma), 쓰고 · 지키고 · 다시 배포하기, 실시간으로 보여 주기, 웹앱 속 AI, 그리고 **웹앱에 붙일 수 있는 감각(모달리티)** 과 그 감각을 파는 요즘 서비스들. 오후에는 어제의 웹 저장소에서 퀘스트 두 개를 깹니다. 하루가 끝나면 **누구의 휴대폰에서도 같은 기록이 보이는 내 웹앱**과 **AI가 써 두고 사람이 누르는 승인 대기열**이 남습니다.

## 오전 이론 한눈에 {#theory}

네 장(챕터)을 교시 순서대로 줄였습니다. 장 전체는 [강의 슬라이드 PDF](#slides)에 있습니다.

### 1교시 · 09:00–09:50 — 1장 데이터를 저장하는 웹앱 {#p1}

- **어제의 앱에 오늘 더할 것** — 어제의 층 지도 위에 DB · Prisma · 서버 액션 · 캐시 · 승인 대기열 · 감사 기록이 올라갑니다.
- **CSV 파일과 데이터베이스** — 배포한 서버는 쓴 파일을 지켜 주지 않고, 여럿이 동시에 쓰면 부딪힙니다. '확인 기록'이 내일도 남아야 하면 **DB**입니다.
- **표와 키** — 바이어 하나에 확인 기록 여럿(1:N). 행마다 하나뿐인 번호(PK)와 다른 표를 가리키는 값(FK) — 없는 번호는 DB가 거절합니다.
- **Supabase** — 클라우드에서 빌리는 PostgreSQL. '관리인 딸린 임대 창고'입니다. 오늘은 DB · 표 편집기 · Connect 단추만 씁니다. 무료는 프로젝트 2개 · 일주일 안 쓰면 일시정지. DB 비밀번호는 금고 열쇠, 지역은 서울.
- **연결 주소와 풀러** — 앱이 DB를 찾아가는 주소 + 열쇠 한 줄(서버에만). `DATABASE_URL`은 트랜잭션 풀러 6543(앱 · Vercel), `DIRECT_URL`은 세션 풀러 5432(표를 바꾸는 명령). 커밋 · 채팅 · 캡처에는 남기지 않습니다.
- **ORM과 Prisma** — 표를 코드의 객체처럼 다루게 하는 통역사. `schema.prisma`가 표 설계도이고 사람이 읽고 승인합니다. 마이그레이션(DB 구조 변경의 이력 = DB의 커밋)은 개념만 보고, 실습은 `npm run db:push`로 합니다. Prisma 7은 새 판이라 AI가 옛 문법을 쓸 수 있어 스타터를 따릅니다.
- **화면에서 읽기 · 자주 보는 DB 오류** — 서버 컴포넌트에서 `findMany`(= 2일차 SQL의 SELECT). 오류는 전문과 주소의 '모양'(비밀번호는 ●●●)을 함께 AI에게.

### 2교시 · 10:00–10:50 — 2장 쓰고 · 지키고 · 다시 배포 → 3장 실시간으로 보여 주기 {#p2}

- **서버 액션** — 단추 · 폼을 누르면 서버에서 도는 함수(창구). 입력 검사 → 저장 → 화면 새로 그리기(`revalidatePath`). 공개 창구라 입력 검사가 필수입니다.
- **읽기 · 쓰기 · 외부 공개 — 어디에** — 서버 컴포넌트(읽기) · 서버 액션(쓰기) · route handler(바깥에 여는 주소) · 클라이언트 컴포넌트(화면 움직임).
- **환경 변수** — 코드 밖 설정값. 내 PC는 `.env`, Vercel은 설정 화면. `.env.example`에는 이름만. 값을 바꾸면 **Redeploy**. `NEXT_PUBLIC_`으로 시작하면 브라우저 코드에 박힙니다.
- **배포한 뒤 자주 보는 일 · 배포한 앱의 보안 다섯 줄** — 500 오류는 로그부터, 친구 화면의 로그인 창은 긴 배포 주소. 비밀은 서버에만 · `NEXT_PUBLIC_`에 비밀 금지 · 공개 앱은 가상 데이터만 · 쓰기 단추는 누구나 누른다(검사 · 확인 · 기록) · 키가 새면 폐기 · 재발급부터.
- **RLS(행 단위 보안)** — 층별 출입증. 브라우저가 Supabase를 직접 부를 때 꼭 필요하고, 우리 앱은 서버에서 Prisma로 읽으니 앱 코드가 문지기입니다. 그래도 `npm run db:push`가 표마다 RLS를 켜 둡니다 — RLS를 켜지 않아 DB 전체가 열려 있던 바이브 코딩 앱 사고가 실제로 있었습니다.
- **실시간으로 보여 주기 — 캐시 · 재검증 · 신선도** — 환율 타일은 서버 창구(`/api/fx`)가 60초 동안 같은 답을 재사용하고(`revalidate = 60`), 화면은 60초마다 다시 묻고, 실패하면 저장본(대체 값)을 보여 줍니다. 타일에는 늘 **받은 시각 · 제공처 · 대체 값 표시**. 캐시는 개발 모드가 아니라 **배포 주소**에서 확인합니다.
- **4장 시작 — AI가 앱에 들어오는 두 길** — 만들 때 미리(Claude Code · `claude -p`가 초안을 써 둔다 = 오늘의 기본 · 키 없음) / 돌아갈 때(앱이 실행 중에 AI를 부른다 = 키 · 비용 · 지연 · 선택). 에이전트 해부(모델 · 도구 · 반복 · 멈춤 조건 · 권한).

### 3교시 · 11:00–11:50 — 4장 웹앱 속 AI → 웹앱에 감각 붙이기 {#p3}

- **워크플로냐 에이전트냐** — 어제의 메일 당번 로봇은 순서가 정해진 워크플로입니다. 가장 단순한 해법부터.
- **독촉 — 단계 · 말투 · 넘지 않는 선** — 연체일로 단계를, 등급으로 말투를 정하고(코드), 넘지 않는 선(계좌 안내 · 법적 위협 · 지어낸 금액 금지)은 검사 규칙으로 막습니다.
- **승인 대기열 · 감사 기록** — 초안 → 승인 / 반려(사유) — 수업 중 발송은 0통. 누가 · 언제 · 무엇을 했는지 한 줄씩, **지우지 않고 쌓습니다.** 되돌릴 수 없는 행동은 사람이 누릅니다.
- **가드레일과 프롬프트 인젝션** — 바이어 메모 속 숨은 지시에도 흔들리지 않게: 출력 검사 + 사람 승인 + 기록을 겹칩니다.
- **RAG — 근거로만 답하게** — 질문과 관련된 문서 조각을 먼저 찾고 그 조각만 근거로 답하기(오픈북 시험). 근거가 없으면 모른다고.
- **웹앱에 감각 붙이기 — 모달리티** — 듣기 · 말하기 · 읽기 · 보기 · 그리기 · 영상 · 알리기 · 통역 · 지도. 감각 지도 → 감각별 요즘 서비스 → 붙이는 네 가지 길 → 키 없이 30줄 → 붙일 때 지킬 것. 아래 [감각 붙이기](#modality)에 한 장으로 정리했습니다.
- **앱 안에서 AI를 부르려면(선택)** — AI SDK · 게이트웨이 · 키는 서버에만 · 스트리밍 · 시간 제한 · 실패 시 대체 문장 · 비용 = 호출 수 × 토큰 × 단가.
- **만든 뒤가 진짜 일 — 운영** · 오후 실습 C · D 안내 · 쇼케이스 · 내일 준비.

## 웹앱에 감각 붙이기 — 모달리티 {#modality}

**모달리티**는 정보가 오가는 감각의 종류입니다. 글만 주고받던 웹앱에 귀(듣기) · 입(말하기) · 눈(읽기 · 보기) · 손(그리기 · 영상) · 확성기(알리기)를 붙이면 "이런 것까지 된다고?"가 시작됩니다. 아래 서비스 이름은 **2026-10-17에 공식 문서 · 요금 페이지로 확인한 것**만 골랐습니다. 요금과 판은 자주 바뀌니 쓰기 전에 공식 페이지를 다시 봅니다.

| 감각 | 무엇을 | 업무 예(가상) | 요즘 서비스 예 | 키 없이? |
|---|---|---|---|---|

### 붙이는 네 가지 길 {#four-ways}

<div class="grid cards tf-cols-2" markdown>

-   **① 브라우저 내장 — 키 없음 · 무료**

    음성 인식 · 음성 합성 · 알림 · 공유 · 위치 · 카메라 · (크롬) 번역 · 요약. 사용자가 '허용'만 누르면 됩니다. 브라우저마다 되는 것이 다릅니다.

-   **② 서버 API — 키는 서버에**

    OCR · 이미지 · 영상 · 메일 · 문자. 우리 서버 창구(route handler)가 키를 들고 대신 부르고, 키는 `.env`와 Vercel 환경 변수에만 둡니다.

-   **③ AI SDK · 게이트웨이 — 모델을 갈아 끼우기**

    같은 코드에서 모델 이름 한 줄만 바꿔 여러 회사 모델을 씁니다. 비용 상한과 대체 문장을 꼭 둡니다.

-   **④ 노코드 · 웹훅 · MCP — 이미 쓰는 도구에 잇기**

    웹훅 = 일이 생기면 정해 둔 주소로 알려 주는 초인종. 자동화 도구(Zapier · Make · n8n)로 잇거나, MCP로 AI에게 '도구 손잡이'를 줍니다.

</div>

**키 0개 요령** — 만들 때 Claude Code가 사진 · PDF를 읽고 정해 둔 칸(JSON)으로 써 두면, 웹앱은 실행 중에 키 없이 그 JSON만 읽습니다. 오늘 실습 D의 독촉 초안(`npm run drafts`)과 같은 방식입니다.

### 키 없이 30줄 — 브라우저가 듣고 말한다 {#no-key}

브라우저에 들어 있는 Web Speech API면 가입도, 키도, 서버도 없습니다. 핵심은 이 정도입니다 — 2부 자유 퀘스트에서 "키 없이 말하는 버튼을 붙여 줘"라고 해 보세요.

```js
// 말하기(TTS) — 글을 목소리로
const u = new SpeechSynthesisUtterance("한빛정밀 웹앱입니다. 오늘 승인할 초안을 확인해 주세요.");
u.lang = "ko-KR";
speechSynthesis.speak(u);

// 듣기(STT) — 말을 글로(크롬 · 엣지 · 사파리는 webkit 접두어)
const Rec = window.SpeechRecognition || window.webkitSpeechRecognition;
const rec = new Rec();
rec.lang = "ko-KR";
rec.onresult = (e) => console.log(e.results[0][0].transcript);
rec.start();
```

- 단추를 눌렀을 때 실행되게 만들고(브라우저가 자동 재생을 막습니다), 듣기는 마이크 '허용'이 필요합니다. 한국어 목소리는 기기에 깔린 음성에 따라 다릅니다.
- 듣기는 크롬 · 엣지에서 기본으로 소리를 브라우저 회사의 클라우드로 보내 처리합니다(파이어폭스 정식판은 아직 안 됩니다) — **가상 문장으로만** 시험합니다. 처음 누를 때는 목소리 목록이 비어 있을 수 있어 두 번째부터 한국어 목소리가 잡히기도 합니다.

### 붙일 때 지킬 것 {#modality-rules}

<div class="tf-rules" markdown>

1. **개인정보** — 서류 · 명함 · 얼굴 · 목소리는 개인정보입니다. 실습은 가상 데이터만, 실제 서류는 올리지 않습니다.
2. **동의** — 녹음 · 촬영 · 위치는 먼저 알리고 허락을 받습니다.
3. **저작권 · 초상권** — 남의 얼굴 · 목소리 · 로고로 만들지 않습니다. 실습은 가상 회사와 기본 아바타로.
4. **생성물 표시** — AI가 만든 이미지 · 영상 · 음성에는 'AI 생성'을 보이게 붙입니다(우리나라 AI 기본법이 2026년 1월 시행).
5. **비용 상한** — 키를 쓰는 기능은 하루 한도와 실패 시 대체 문장을 먼저 둡니다. 결제 화면이 나오면 멈춥니다.
6. **키는 서버에** — 브라우저 코드 · 저장소 · 채팅에 키를 두지 않습니다. 웹훅 주소도 비밀번호입니다.
7. **사람 확인** — 보내기 · 결제 · 삭제처럼 되돌릴 수 없는 일은 사람이 누릅니다.

</div>

## 17:00 쇼케이스 {#showcase}

어제와 같은 방식입니다.

1. **16:50까지** 오픈채팅에 한 줄 — `[발표] T{조}-{번호} / 별명 / C 또는 D / 한 줄 / 링크`
   <br>예) `[발표] T2-07 / 바다 / D / AI는 초안만, 보내는 건 팀장 / https://tradefin-web-t2-07.vercel.app/dunning`
2. 링크는 **운영 주소**(짧은 주소)로 — 시크릿 창에서 열리는지 먼저 봅니다.
3. 한 사람 **2분 · 4문장** — 불편(상황) → 화면 → 안 된 것 → 이렇게 고쳤다 / 내 업무라면. 1:45 노랑 · 2:00 종. 발표하는 사람이 많으면 90초로 줄입니다(17:00에 안내).
4. 보여 주기 좋은 장면 — 옆 사람 휴대폰으로 확인 기록 하나 쓰기 · 초안 하나 승인 · 감사 기록이 한 줄 느는 화면. 승인 코드 · DB 비밀번호가 화면에 보이지 않게 합니다.
5. 다섯 명이 끝날 때마다 1분 휴대폰으로 눌러 보기 → **17:40 투표**(마음에 드는 발표 2개에 공감 · 내 팀 제외) → 17:46 TOP 3 → 내일 준비.

**내일 준비 — 오늘 밤 숙제 15분.** 내일은 내 아이디어로 하루 해커톤입니다. [아이디어 씨앗 → 숙제](../day6/hack-ideas.md#homework)대로 씨앗 하나를 고르거나 '내 일에서 귀찮은 것 하나'로 정해 아이디어 카드의 별표 다섯 칸(앱 이름 · 누가 · 언제 여나 · 불편 숫자 하나 · 성공의 순간)만 채워 옵니다. 내일 09:50까지 오픈채팅에 `[아이디어] T{조}-{번호} / 앱 이름 / 한 줄`.
