#### 단계와 말투 — 코드가 정한다 {#stage-tone}

가장 오래 밀린 인보이스가 기일을 며칠 넘겼나(`oldestOpenDays`)로 단계를 정하고, 말투 표(`data/tone_matrix.csv`)에서 단계 × 등급으로 말투를 고릅니다. AI는 이 두 가지를 정하지 않고, 받은 대로 씁니다.

| 가장 오래 밀린 날 | 단계 | 말투(S · A · B 등급) | 말투(C 등급) |
|---|---|---|---|
| 30일 이상 | D+30 | T3 마지막 안내 | T3 마지막 안내 |
| 15–29일 | D+15 | T2 단호하게 · 7일 안에 | T2 단호하게 · 7일 안에 |
| 7–14일 | D+7 | T1 상냥한 알림 | T2 단호하게 · 7일 안에 |
| 1–6일 | 대기 | 초안을 쓰지 않는다 | 초안을 쓰지 않는다 |

T3도 '다음 선적을 보류할 수 있다'까지만 씁니다 — 소송 · 경찰 같은 법적 표현은 쓰지 않습니다.

#### 검사 7개(G1–G7) — 코드가 채점 {#guardrails}

AI가 쓴 초안은 저장하기 전에 코드가 일곱 가지를 봅니다. **하나라도 걸리면 '막힘'**으로 저장되고 승인 단추가 없습니다.

| 검사 | 보는 것 | 왜 |
|---|---|---|
| G1 금액 정확 | 본문에 그 바이어의 연체 금액이 `USD 24,530.00`처럼 정확히, 다른 금액은 없이 | 옆 팀의 사과 메일 두 통 |
| G2 바이어 이름 | 바이어 이름이 글자 그대로 | 남의 회사 이름으로 독촉하면 사고 |
| G3 계좌 없음 | 계좌 · IBAN · SWIFT · 'new account'가 없다 | '그 사기꾼'이 가장 좋아하는 말이 '새 계좌로 보내 주세요'입니다. 우리 메일엔 계좌가 한 글자도 없어야, 가짜 메일이 섞여도 바이어가 알아챕니다 |
| G4 법적 표현 없음 | 소송 · 법적 조치 · 법원 · 경찰 · 변호사 · 형사 같은 말이 없다 | 독촉은 협박이 아니다 |
| G5 이미 냈다면 | `If you have already paid, please disregard this message.` 한 줄 | 이미 낸 바이어를 화나게 하지 않게 |
| G6 길이 | 본문 180단어 이하 | 팀장님이 휴대폰으로 읽는다 |
| G7 링크 · 메일 주소 | 링크가 없고, 메일 주소는 고정 발신 주소 하나뿐 | 피싱처럼 보이지 않게 |

### D-1 · 01 퀘스트 1 · 환율 레이더 켜기 (15:00–15:15) { #d1-1 .step data-tool="Claude Code · 브라우저" }

!!! me "내가 할 일"

    1. 웹 저장소 창에서 `npm run dev`가 돌고 있는지 봅니다(없으면 터미널 ++ctrl+grave++ → `npm run dev`).

## 채팅 경로 — Claude Code를 못 쓸 때 {#chat-path}

실습 D는 터미널(`db:push` · `npm run drafts`)이 필요한 단계가 많습니다. Claude Code를 쓸 수 없으면 둘 중 하나로 합니다.

1. **Codespaces** — 웹 저장소 GitHub 화면의 **Code → Codespaces**에서 브라우저 안의 VS Code로 같은 쪽을 그대로 따라 합니다 → [웹 작업대 · Codespaces](../web.md#codespaces)
2. **환율 타일만 채팅으로** — claude.ai 새 대화에 `guide/day5_lab_d.md` · `data/fx_fallback.json` · `data/README.md` · `app/page.tsx` · `lib/metrics.ts` · `lib/format.ts`를 첨부하고(파일이 없으면 [스타터 ZIP](#files)에서), 아래 **채팅 시작** 문장 → d1을 보냅니다. 받은 파일 내용을 GitHub 웹 **Add file → Create new file**(있는 파일은 연필 단추)로 붙여 넣고 `main`에 커밋하면 Vercel이 배포합니다. 표 · 초안 · 대기열은 짝의 PC에서 함께 합니다.

내 PC에서 Node · DB는 되는데 AI 엔진만 안 될 때는 '초안만 채팅으로' — `npm run drafts -- --dry-run` 출력 전체(두 줄 + 대상 목록 — 바이어마다 번호 · 이름 · 단계 · 말투 · 금액 글자)를 붙여 넣고 `data/dunning_templates.md` · `data/tone_matrix.csv` · 안내서를 첨부해 초안 JSON을 받습니다. VS Code 탐색기의 **새 파일**에 `workbench/drafts_chat.json`을 경로째 넣으면 폴더도 함께 생깁니다 — 거기에 붙여 넣고 저장한 뒤 `npm run drafts -- --import workbench/drafts_chat.json`을 돌립니다. 검사 7개는 코드가 그대로 채점합니다.
