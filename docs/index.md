## 이 사이트 쓰는 법

**일차 페이지는 네 갈래입니다** — 개요(그날의 목표 · 시간표 · 시연 · 결과물), 이론 요약, 실습 A(4–5교시), 실습 B(6–7교시). 복사해 쓰는 프롬프트는 일차별 [프롬프트 라이브러리](prompts/day1.md)에도 모여 있습니다.

**길은 두 가지** — 기본은 내 PC의 VS Code + Claude Code + GitHub입니다. Claude Code 계정이 없거나 설치가 막힌 분은 각 실습 페이지의 **채팅 경로**(ChatGPT · Claude 웹 + GitHub 웹 화면)로 같은 결과를 만들 수 있고, 설치가 막힌 PC는 [Codespaces](setup.md#codespaces)도 됩니다. 길은 언제든 바꿔도 됩니다.

**복사 버튼** — 프롬프트 · 코드 상자의 오른쪽 위 :material-content-copy: 아이콘을 누르면 통째로 복사됩니다.
붙여 넣은 뒤에는 `{중괄호}` 칸만 내 상황에 맞게 바꿉니다.

**막히면**

1. 노트북 위에 **빨간 표시**(스티커 등)를 올립니다(다 끝나면 초록). 강사 · 도우미가 갑니다.
2. [FAQ · 트러블슈팅](faq.md)에서 증상을 찾아봅니다.
3. 바로 답하기 어려운 실무 질문은 메모해 두었다가 쉬는 시간이나 다음 날 아침에 물어 주세요. 강사가 확인해서 답합니다.

!!! warning "AI 대화창은 외부 채널입니다"
    오늘 실습 데이터는 전부 가상(합성)입니다. 회사 실데이터 · 개인정보는 어떤 AI 도구에도, 공개 저장소에도 올리지 않습니다 — 익명화본도.
