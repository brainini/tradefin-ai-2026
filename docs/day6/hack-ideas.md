## 좋은 퀘스트의 네 조건 {#good}

<div class="grid cards tf-cols-2" markdown>

-   :material-numeric-1-circle-outline:{ .lg .middle } **내 불편**

    내가(또는 옆자리가) 매주 겪는 일이고, 숫자 하나로 말할 수 있다 — "매주 금요일 30분", "한 달에 두 번 실수".

-   :material-numeric-2-circle-outline:{ .lg .middle } **한 장면**

    3분 안에 눌러 보여 줄 장면이 하나 있다 — 이런 상황에서(Given) · 이걸 누르면(When) · 이게 보인다(Then).

-   :material-numeric-3-circle-outline:{ .lg .middle } **가상 데이터**

    20–200줄의 가상 데이터로 시연된다. 회사 실데이터 · 실명 · 실제 연락처는 쓰지 않는다 — 열 이름과 모양만 빌린다.

-   :material-numeric-4-circle-outline:{ .lg .middle } **오늘 안에**

    화면 3개 이하 · 쓰기 동작 1개 이하 · 로그인 없음 · 키 없는 것만 — [MVP 규칙](hack.md#mvp).

</div>

## 아이디어 카드 13칸 {#card}

새 저장소의 `hackathon/00_idea_card.md`와 같은 칸입니다. 예는 오 주임의 '택배 왔숑'입니다.

| 칸 | 쓰는 법 | 예 — 택배 왔숑 |
|---|---|---|
| 별명 | 발표 때 부를 이름 | 오 주임 |
| ★ 앱 이름 | 짧고 기억에 남게 | 택배 왔숑 |
| ★ 누가(직무) | 이 앱을 여는 사람 하나 | 총무팀 택배 담당 · 받는 직원 |
| ★ 언제 여나 | 상황 하나 | 택배가 로비에 도착했을 때 · 점심 먹고 돌아올 때 |
| 지금 방식 | 지금은 어떻게 하나 | 단톡방에 사진 한 장씩 올리고 이름을 부른다 |
| ★ 불편(숫자 하나) | 시간 · 횟수 · 실수 | 하루 15건, 찾아가지 않은 택배가 늘 3–4개 |
| 이 앱으로 | 한 줄 | 도착 등록 → 받는 사람 화면에 '도착' → '찾아감' 누르면 목록에서 빠진다 |
| 화면 한 장(글로) | 첫 화면에 무엇이 보이나 | 맨 위 '찾아가지 않은 택배 4', 아래 도착 목록, 사흘 넘은 줄은 노란색 |
| 데이터(가상 · 몇 줄) | 무엇을 몇 줄 | 택배 15줄 — 도착 시각 · 받는 부서 · 이름(김○○) · 상태 |
| ★ 성공의 순간 | 발표에서 보여 줄 한 장면 | 휴대폰에서 '찾아감'을 누르면 숫자가 4 → 3으로 바뀐다 |
| 저장 필요? | 없음 · 내 기기 · 여럿이 같이 | 여럿이 같이 → DB |
| AI는? | 만들 때만 · 앱 안에서도 | 만들 때만 |
| 혼자 / 짝 | 짝이면 짝 번호 | 혼자 |

## 씨앗을 내 것으로 바꾸는 법 {#remix}

1. **사람을 바꿉니다** — 누가 여는지. 총무팀의 비품 재고 → 연구소의 시약 재고 → 공장의 안전 장비 점검.
2. **데이터를 바꿉니다** — 열 이름만 내 업무에서 빌리고, 값은 가상으로 지어냅니다.
3. **장면 하나만 남깁니다** — 발표에서 누를 단추 하나. 예: "시약 부족 3개가 빨간색, '주문 요청'을 누르면 2개로 줄어든다."
