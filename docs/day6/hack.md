| 항목 | 내용 |
|---|---|
| 형태 | 개인 · 원하면 2인([짝 규칙](#pairs)) |
| 출발점 | 웹 스타터 템플릿 → 새 저장소 `hack-T{조}-{번호}` — 어제까지의 `tradefin-web-…` 저장소와 DB는 **그대로 둡니다** |

| 비밀 | `.env`와 Vercel 환경 변수에만 — 커밋 · 캡처 · 오픈채팅에 올리지 않습니다 |
| 세이브 포인트 | 10:50 · 14:20 · 15:30(코드 프리즈) — 오픈채팅에 한 줄([아래](#savepoints)) |
| 보스전 | 16:00부터 한 사람 3분 · 운영 주소로 시연 → [심사 · 발표 · 투표](hack-rules.md) |
| 막히면 | **10분 규칙** — 10분 넘게 혼자 붙잡지 않고 [도움 사다리](#help)를 한 칸 오릅니다 |

<a id="mvp"></a>

!!! warning "MVP 규칙 — 오늘 만드는 크기"

    - **한 사람 · 한 순간 · 한 동작** — 누가(직무 하나) · 언제(상황 하나) 여는지, 그때 하는 동작 하나
    - 화면 **3개 이하** · 쓰기 동작(저장 · 바꾸기) **1개 이하** · 로그인 없음
    - 가상 데이터만, **200줄 이하** · 바깥 API는 키 없는 것만 · 앱 안 AI는 기본 끔
    - **세이브 포인트 1(10:50)까지 운영 주소에 뼈대**가 떠 있어야 합니다

    크면 자릅니다. 잘라 낸 것은 버리지 않고 `SPEC.md`의 '다음 단계'로 옮깁니다 — 발표의 마지막 20초 재료가 됩니다.

## 세이브 포인트 세 번 {#savepoints}

세이브 포인트는 말이 아니라 **운영 주소와 커밋**으로 확인합니다. 시각이 되면 오픈채팅에 한 줄 올리고, 옆자리 버디와 2분 동안 서로의 주소를 휴대폰으로 열어 봅니다.

| 세이브 포인트 | 시각 | 운영 주소에서 보이는 것 | 오픈채팅 한 줄 | 못 했으면 |
|---|---|---|---|---|
| **1 · 첫 깃발** | 10:50 | 뼈대 — 앱 이름 · 한 줄 · 쪽 이동 · 가상 예시 줄 · 배포 배지 | `[CP1] T2-07 / 주소` | 10:55에 강사가 찾아갑니다 — H3만 다시 |
| **2 · 장면 완성** | 14:20 | 시나리오 1이 Given → When → Then 끝까지(휴대폰에서도) | `[CP2] T2-07 / 주소 / 된 시나리오` | 14:25 강사 방문 · [h-cut](hack-build.md#h-cut)으로 장면 하나만 |
| **3 · 코드 프리즈** | 15:30 | README · 대본 · 점검 FAIL 0 — 이후에는 README · 오타만 고칩니다 | 15:45까지 `[발표] T2-07 / 별명 / 한 줄 / 주소` | 되는 데까지 + 백업 캡처로 발표합니다 |

`T2-07`은 내 조-번호로 바꿉니다. 주소는 **운영 주소**(`hack-t2-07.vercel.app` 꼴)를 올립니다 — `-<영문숫자>-<이름>.vercel.app`처럼 긴 주소는 미리보기 주소라 다른 사람에게는 로그인 화면이 뜹니다.

## 짝으로 할 때 — 2인 규칙 {#pairs}

- **저장소 하나** — 한 사람(주인)의 계정에 만들고, **push는 주인만** 합니다. Vercel 무료 판은 다른 사람의 커밋 배포를 막기도 합니다.
- 코드는 **주인 노트북 한 대**에서 — 30분마다 운전석을 바꿉니다. 짝은 SPEC · 가상 데이터 · 휴대폰 시험 · README · 대본을 맡습니다.
- 세이브 포인트와 `[발표]`는 주인 번호로 올리고 한 줄 끝에 `짝 T2-08`을 붙입니다.
- 발표는 **한 자리 3분**, 두 사람 모두 한마디씩. 심사는 한 팀으로, 공감은 둘이 따로 2개씩 누릅니다.

## 도움 사다리 — 10분 규칙 {#help}

10분 넘게 혼자 붙잡지 않습니다. 한 칸씩 오릅니다.

1. **`npm run doctor`**(DB를 붙였다면 `npm run doctor:db`) — ✗ 줄 옆의 고치는 법을 그대로
2. **[h-fix](hack-build.md#h-fix)** — 오류 끝 10줄을 붙여 원인 후보 3개부터
3. **짝 · 옆자리 버디** — 화면을 같이 보면 반은 풀립니다
4. **오픈채팅** `[도움] T2-07 / 단계 / 증상 한 줄` + 캡처(비밀번호 · 키는 가리고) — 강사 · 조교가 올라온 순서대로 갑니다
5. **방문** — 강사 · 조교가 자리로
6. **[h-cut](hack-build.md#h-cut)으로 범위 줄이기**, 또는 내 저장소 → Code → **Codespaces**로 옮기기

오피스아워(화면으로 10분): **11:30** 배포 · 환경 변수 · 빌드 오류 · **13:40** DB · 저장 · **15:05** 발표 · README.

- 오늘 쓰는 데이터는 모두 **가상**입니다 — 스타터의 (가상) 한빛정밀(주) 합성 데이터, `hackathon/sample_data/`의 가상 CSV 셋, 그리고 내가 AI와 만든 가상 데이터. 이름 옆에는 `(가상)`, 사람 이름은 `김○○`처럼 가리고, 이메일은 `@….example`만 씁니다.
