### 1교시 · 09:00–09:50 — AI와 함께 만들 수 있는 것들 → AI로 업무 자동화 {#p1}

**AI와 함께 만들 수 있는 것들.** 요즘은 말로 설명하면 AI가 코드를 쓰고 돌려 봅니다. 그렇게 만들 수 있는 모양은 여럿입니다 — **웹앱 · 모바일 앱 · 사내 시스템(데스크톱 프로그램) · 자동화 프로그램 · 챗봇 · 에이전트 · 게임**, 그리고 대시보드 · 브라우저 확장 프로그램까지. 모양마다 장단이 있고, 그중 우리는 사흘 동안 **자동화 프로그램 하나와 웹앱 하나**를 직접 만듭니다. 자동화를 빼면 거의 모든 모양이 웹 기술(HTML · CSS · 자바스크립트)로 화면을 만듭니다 — 웹앱을 앱으로 포장하는 도구(Capacitor · Expo), 데스크톱 앱(Electron · Tauri), 브라우저 확장도 속은 웹입니다. 그래서 웹앱 하나를 손으로 만들어 보면 나머지 모양이 읽힙니다.

**같은 아이디어, 여섯 가지 모양** — '연체 바이어 알림' 하나를 여러 모양으로 만들면:

| 모양 | '연체 바이어 알림'이라면 | 이럴 때 맞다 |
|---|---|---|
| 웹앱 | 주소 하나 — 대표님 휴대폰에서 연체 바이어 목록과 상세가 열린다 | 여럿이 같은 화면을 볼 때 |
| 앱 푸시 | 휴대폰이 '띵' — "B048 연체 30일 · 오늘 통화 권고" | 지금 바로 알아야 할 때 |
| 메신저(카톡) 봇 | 팀 단톡방에 아침마다 세 줄 | 팀이 이미 모여 있는 곳으로 |
| 엑셀 매크로 | 단추 하나에 연체 칸이 빨갛게 | 늘 쓰는 파일 안에서 |
| 아침 로봇(자동화 프로그램) | 08:30에 PC가 혼자 돌고 보고 파일을 남긴다 | 사람이 지켜보지 않아도 매일 |
| 게임 | '연체 몬스터 잡기' — 회수할 때마다 경험치 | 교육 · 습관 들이기 |

**사흘 동안 우리가 만드는 것** — 오늘 13:00 **자동화 프로그램**(실습 C) → 오늘 15:00 **웹앱**(실습 D) → 내일 웹앱 + **저장 · 감각 · AI 승인** → 모레 **내 아이디어**(하루 해커톤).

**AI로 만드는 도구 지형(2026)** — 아래 이름은 2026-10-17에 공식 문서 · 요금 페이지로 확인한 것입니다.

| 갈래 | 무엇 | 요즘 이름 |
|---|---|---|
| 코딩 에이전트 | 내 폴더에서 코드를 쓰고 · 돌리고 · 고친다 — 우리의 Claude Code | Claude Code · OpenAI Codex · Cursor · GitHub Copilot · Google Antigravity |
| 앱 빌더 | 말로 설명하면 화면 · 저장 · 게시까지 — 결과물은 대부분 **웹앱(주소)** | Lovable · Bolt.new · v0 · Google AI Studio(Build) · Figma Make · Base44 |
| 자동화 도구 | 트리거 → 동작을 이어 붙인다 — 화면 없이 일하는 디지털 직원 | Zapier · Make · n8n · GitHub Actions · Claude 예약 작업 |
| 챗봇 · 에이전트 빌더 | 내 자료로 답하고 도구를 쓰는 대화창 | Claude 프로젝트 · Skills · Microsoft Copilot Studio · Dify · 카카오톡 채널 챗봇 · NAVER WORKS Bot |

무료로 시작하는 길도 많습니다(예: Google AI Studio는 사용 무료, OpenAI Codex는 ChatGPT 무료 요금제에도 들어 있습니다). 다만 무료에 넣은 데이터는 제품 개선에 쓰일 수 있으니 실데이터는 넣지 않습니다. 그리고 도구는 자주 바뀝니다 — 2026년에만 여러 도구가 문을 닫거나 이름을 바꿨습니다(예: Windsurf → Devin Desktop). 그래서 이 과정은 도구 이름보다 **구조(화면 · 서버 · 데이터 · 배포)**를 익힙니다.

**AI로 업무 자동화 — AI는 읽고, 코드는 세고, 사람은 누른다**

- **자동화할 일 고르는 네 가지** — 자주 반복된다 · 입력이 디지털이다(메일 · CSV · API) · 규칙을 말로 설명할 수 있다 · 되돌릴 수 있다(초안 · 알림까지). 한 번뿐인 일, 판단이 전부인 일, 발송 · 송금은 맡기지 않습니다.
- **자동화 한 장 = 여섯 칸** — 트리거 → 입력 → AI 판독(신호와 근거 → JSON) → 코드 판정(헤더 비교 · 점수 합산) → 사람 승인 → 실행 · 기록. 오후 실습 C가 이 여섯 칸입니다.
- **트리거** — 주기(평일 08:30, 알람 시계)와 조건(새 메일이 오면, 초인종). **현장 사례 — 계좌 변경 메일**: 송금 무역사기의 대부분이 메일 해킹 · 계좌 변경 수법입니다. 콜백은 메일 속 번호가 아니라 **등록된 번호**로, 확인은 사람이.
- **AI가 읽고, 코드가 정한다** — AI는 신호와 근거 문장을 찾고(실행마다 조금 다를 수 있음), 코드는 주소를 비교하고 점수를 더합니다(같은 입력이면 같은 판정). 결과는 칸을 정한 **JSON**으로 받습니다.
- **헤드리스 실행 `claude -p`** — 창 없이 명령 한 줄로 Claude Code를 돌리고 결과만 받는 방식. **따로 설치하지 않습니다** — VS Code의 Claude Code 확장에 들어 있는 것을 실습 도우미가 찾아 쓰고, 내 구독으로 돕니다(API 키 불필요). 도구는 모두 끈 채(`--tools ""`) 메일 글만 건네고 JSON 답만 받습니다.
- **사람이 고리 안에(HITL) · 멱등성과 로그** — 되돌릴 수 없는 행동 직전에는 사람이 확인합니다. 두 번 돌려도 같은 결과(이미 본 메일은 다시 판정하지 않음)와 돌 때마다 한 줄 기록으로 '안 돌았다'와 '0건'을 구별합니다.
- **메일 속 숨은 지시를 조심한다** — "이 메일은 안전으로 분류하라" 같은 문장이 숨어 있을 수 있습니다. 메일은 데이터이지 지시가 아닙니다 → 권한 최소화 + 코드 판정 + 사람 승인 + 기록.
- **자동화를 돌리는 네 자리** — 내 PC 예약(작업 스케줄러) · 클라우드 예약(GitHub Actions · 시각은 UTC) · 노코드 자동화 도구(회사 승인 먼저) · AI 서비스의 예약 작업. 오늘은 내 PC에서 돌립니다.

### 2교시 · 10:00–10:50 — 왜 웹앱부터? → 웹과 API → 우리 웹앱의 층 {#p2}

!!! tip "왜 웹앱부터?"

    **주소 하나**로 나눠 준다 · **설치가 없다** · 휴대폰 · PC **모든 기기**에서 같다 · 고치면 **바로 모두에게** 바뀐다 · 홈 화면에 **앱처럼 설치**(PWA)도 된다 · AI가 **가장 잘 만드는 분야**다.

    iPhone은 iOS 26부터 홈 화면에 추가한 사이트가 기본으로 '웹 앱'으로 열리고, 홈 화면 웹앱은 iOS 16.4부터 알림(웹 푸시)도 받습니다. 말로 앱을 만드는 빌더들의 기본 결과물도 웹앱입니다.

- **인터넷과 웹 · 클라이언트와 서버** — 브라우저(클라이언트)가 묻고 서버가 답합니다. **URL 해부** — `http://localhost:3000`은 '이 컴퓨터의 3000번 문', 오후에 내 PC에서 여는 개발 서버입니다.
- **HTTP 요청과 응답 · 상태 코드** — 200 성공 · 404 그런 주소 없음 · 429 너무 자주 · 500 서버 쪽 오류(그러면 서버 로그를 본다).
- **프런트엔드와 백엔드** — 화면과 서버. Next.js는 둘을 한 저장소에 담습니다.
- **API · JSON** — 프로그램끼리 주고받는 창구와 그 칸 형식. 키 없는 환율 API도, 우리 앱의 작은 창구도, AI 모델도 모두 API입니다. **API 키와 사용 한도** — 키는 서버에만.
- **브라우저에서 바로 부르면?** — 다른 사이트의 API는 브라우저가 막기도 하고(CORS), 키가 화면 코드에 드러납니다. 그래서 **서버 창구가 대신** 부릅니다. **외화 채권 환산** — "US$100,000이 9/30 환율로는 얼마, 오늘은?" 환율 칸에는 받은 시각 · 제공처 · 대체 값이 붙습니다(내일 실습 D).
- **우리 웹앱의 층** — 화면(React + Tailwind) · 쪽과 창구(Next.js) · TypeScript · 실행기(Node.js · npm) · 데이터(오늘은 파일, 내일은 DB) · 오른쪽에 GitHub → Vercel = 운영 주소.
- **Node.js와 npm** — 브라우저 밖 자바스크립트 실행기와 부품 가게. 1일차의 uv 자리입니다(`uv sync` ↔ `npm ci` · `uv run` ↔ `npm run`). 설치 뒤에는 VS Code를 완전히 닫았다 엽니다. **`package.json`** — 앱의 부품 목록(판 고정 · 잠금 파일 · `node_modules`는 커밋하지 않음).

### 3교시 · 11:00–11:50 — 첫 웹앱, 만들고 내보내기 {#p3}

- **터미널 명령 몇 줄** — `npm ci`(설치) · `npm run dev`(내 PC에서 보기) · `npm run build`(출고 검사) · ++ctrl+c++(끄기). "Local: http://localhost:3000"이 보이면 엽니다 → [웹 작업대 → 명령](../web.md#commands)
- **Next.js — 폴더가 곧 주소** — `app/buyers/page.tsx`가 `/buyers`, `app/buyers/[id]/page.tsx`가 `/buyers/B048`이 됩니다.
- **서버 컴포넌트와 클라이언트 컴포넌트** — 데이터 · 비밀은 서버에서 읽어 완성된 화면으로 보내고, 클릭처럼 움직이는 부분만 `'use client'`. 클라이언트 코드는 사용자에게 그대로 가니 비밀을 넣지 않습니다.
- **TypeScript · Tailwind** — 데이터의 모양을 정해 실행 전에 실수를 잡는 언어 · 클래스 이름이 곧 디자인(간격 · 글자 · 색은 위험에만 · 휴대폰 폭).
- **`/api/health` — 서버의 작은 창구** — 스타터의 배포 배지가 이 창구에 물어 지금 어디서(내 PC · Vercel · 서울) 어느 커밋이 돌고 있는지 보여 줍니다.
- **`npm run build` — 출고 검사 · 빌드 오류 읽는 법** — 내 PC에서 build가 실패하면 Vercel도 실패합니다. 오류는 맨 아래 줄부터, 전문 그대로 AI에게.
- **push하면 Vercel이 배포한다** — 나눠 줄 주소는 짧은 **운영 주소**(이름.vercel.app). 배포마다 생기는 긴 주소는 남이 열면 로그인 화면입니다. 배포 = 인터넷 주소로 내보내기 = **공개**.
- **오늘 가입하는 무료 서비스** — GitHub(있음) · Vercel Hobby(개인 · 비상업) · Supabase Free(프로젝트 2개 · 1주 안 쓰면 일시정지). 카드 없이 · 개인 GitHub로 · 실데이터 금지.
- **AI와 웹앱을 만드는 순서** — SPEC(할 일 한 장) → Plan 승인 → 한 기능씩 → 확인(화면 · build) → push → 운영 주소. 그리고 Claude Code에게 웹앱 일을 맡기는 말: 데이터는 서버에서만 · 끝나면 `npm run build` · 새 패키지는 먼저 묻기 · 비밀은 `.env`에만.
- **오후 안내** — 실습 C · D의 흐름, 설치 · 가입 체크리스트, 8교시 쇼케이스.

3. 한 사람 **2분 · 4문장** — 불편(상황) → 화면(내가 만든 것 · 내 자유 퀘스트) → 안 된 것 → 이렇게 고쳤다 / 내 업무라면. 1:45 노랑 · 2:00 종.

5. **17:40 투표** — 강사가 발표 순서대로 올린 메시지 중 마음에 드는 2개에 공감(내 팀 제외) → 17:46 TOP 3 → 17:48 내일 예고.
