## 이 퀘스트의 규칙 — 로봇 한 대의 분업 {#rules}

오늘의 로봇은 일을 넷으로 나눕니다. 오전에 본 '여섯 칸'이 그대로 파일과 명령이 됩니다.

| 칸 | 누가 | 오늘 로봇에서는 |
|---|---|---|
| 트리거 | 사람(2부에서는 시계) | 내가 터미널에 `uv run python scripts/mail_bot.py` 한 줄 |
| 입력 | 코드 | 받은편지함 세 폴더의 `.eml` · 연락처 · 바이어 평소 모습 |
| 헤더 검사 | **코드** | 보낸 주소 ↔ 등록 도메인(④ 유사 도메인) · 회신 주소(⑤) — 철자 하나도 코드가 정확히 본다 |
| 본문 판독 | **AI** | 메일마다 AI 엔진 한 번 — 신호 번호와 **본문 그대로의** 근거 문장만. 근거가 본문에 없으면 코드가 버린다 |
| 합산 · 상태 | **코드** | 점수표대로 더해 멈춤 · 확인 · 기록. 메일 속 'AI에게 보내는 지시'는 코드가 따로 찾아 표시한다 |
| 결정 · 실행 · 기록 | **사람** · 코드 | 콜백은 등록 번호로, 결정은 사람이. 로봇은 보드 · 장부 · 실행 기록만 쓴다(답장 · 송금 · 전달 없음) |

**왜 AI는 `--no-ai`로만 시험하나** — Claude Code 안에서 또 다른 AI를 부르면 둘이 엉킵니다. 그래서 Claude Code는 규칙만으로 도는 `--no-ai`로 코드가 맞는지 보고, AI 엔진이 도는 진짜 실행은 내가 합니다. 그 덕에 '로봇 = 명령 한 줄'이 손에 잡힙니다. `--no-ai` 결과는 `workbench/day4/outputs/no_ai/`에 따로 생겨 내 실행 결과를 덮지 않습니다.
