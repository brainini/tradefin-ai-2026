## 파일 받기 {#files}

1. 아래 표 맨 위 **`day1_files.zip`** 줄의 **받기**를 누릅니다. 오늘 쓰는 파일이 전부 들어 있습니다.
2. 파일 탐색기(Mac: Finder)에서 **다운로드** 폴더를 엽니다.
3. 받은 zip 파일을 마우스 오른쪽 버튼으로 누르고 **모두 압축 풀기** → **압축 풀기**를 누릅니다. (Mac: zip 파일을 더블클릭)
4. 압축이 풀린 창에 보이는 **`D1`** 폴더를 바탕화면으로 끌어다 놓습니다.
5. `D1` 폴더를 열어 확인합니다. 보고서 발췌(`irobot.md` 같은 `.md` 파일)는 **`D1` → `reports`** 폴더에, 나머지 파일은 `D1` 바로 안에 있습니다.

필요한 파일만 하나씩 받아도 됩니다. 그럴 때는 바탕화면에 `D1` 폴더를 직접 만들고, 받은 파일을 그 폴더로 옮깁니다.

## 산출물과 제출 {#submit}

**제출 파일 하나**: 템플릿에 오늘 결과를 모은 뒤 `d1_end_eda__T{조}-{번호}.xlsx` 이름으로 저장합니다.
번호는 두 자리로 씁니다. 예: 2조 7번 → `d1_end_eda__T2-07.xlsx` (밑줄 두 개, 대문자 T, 하이픈)

1. 엑셀에서 **파일** → **다른 이름으로 저장** → **찾아보기**를 누릅니다.
2. `D1` 폴더를 고릅니다.
3. 파일 이름 칸에 `d1_end_eda__T조-번호`를 입력합니다(예: `d1_end_eda__T2-07`).
4. 파일 형식이 **Excel 통합 문서(\*.xlsx)**인지 확인하고 **저장**을 누릅니다.
5. [제출 폼 링크 — 강사 입력]을 열고 Google 계정으로 로그인합니다.
6. **파일 추가**를 눌러 저장한 파일을 올리고 **제출**을 누릅니다. 마감은 **17:40 미닛카드 전**입니다.

- 다 끝내지 못했어도 그대로 제출하세요. 내일 09:00에 강사 정답 파일(체크포인트)이 올라와 그 파일로 이어 갑니다.

## 함께하는 규칙 {#rules}

- **페어**: Lab2는 두 사람이 한 화면으로 합니다. 한 사람은 마우스·키보드(드라이버), 한 사람은 지시와 확인(내비게이터). 25분마다 바꿉니다.
- **스티커**: 막히면 노트북 뚜껑에 빨강, 다 끝나면 초록.
- **새 일 = 새 채팅**: 한 채팅에서는 문서(파일) 하나만 다룹니다. 같은 문서로 이어 가는 프롬프트(예: P1-1 → P1-2)는 같은 채팅에, 다른 문서나 다른 일은 새 채팅에서 시작합니다. 대화가 길어지면 AI가 앞의 지시를 놓칩니다.
- **파킹랏**: 강사도 모르는 현장 질문은 벽 전지나 Slido에 적습니다. 다음 날 1차 자료로 답합니다.

    3. **고치기 전에 진단부터** — AI에게도 "수정 금지"라고 말한다.
