# 5일차 프롬프트 — 실습 C(수업판) 사라지는 수첩 미스터리

실습 C '사라지는 수첩 미스터리 — 확인 기록 · DB 붙이기'에서 쓰는 프롬프트입니다. 실습 쪽의 단계 번호(실습 C-1 · 01 …)와 맞춰 두었습니다. 복사 버튼 :material-content-copy: 으로 통째로 복사해 **웹 저장소**(`tradefin-web-T{조}-{번호}`) 창의 Claude Code 입력창에 붙여 넣습니다. 바꿀 자리는 `{중괄호}`이고, 중괄호 기호도 지웁니다.

- 프롬프트마다 첫 줄은 **목적**(지금 무엇을 위해 하는지), 다음 줄은 **할 일**입니다. 표 설계(모델 글) · 처음 데이터 · 쪽 바꾸기 · 확인 기록 검사 규칙 · 커밋 규칙처럼 긴 내용은 **작업 안내서** `guide/day5_lab_c.md`에 절마다 적어 두었고, 프롬프트는 '「2. 표 설계」대로'처럼 그 절을 가리킵니다. 안내서는 열어 읽어도 됩니다(고치지는 않습니다 — 새 판은 `npm run guide:update`).
- **비밀번호 · 연결 주소는 어떤 프롬프트에도 쓰지 않습니다.** `.env`는 내가 직접 채우고, AI는 열지 않습니다(저장소 설정이 막아 둡니다). DB 상태는 `npm run doctor:db` 결과(비밀번호가 가려짐)로 봅니다.
- 표 만들기 `npm run db:push` · 데이터 넣기 `npm run db:seed`는 AI가 허락 창으로 묻습니다 — 읽고 승인합니다. '데이터가 지워질 수 있다(data loss)'는 말이 보이면 고르지 말고 손을 듭니다.
- AI는 답 끝에 '확인할 것' 3줄을 보여 줍니다. 그 3줄을 실습 쪽의 '확인할 것'과 견줍니다.

<!-- --8<-- [start:c-free] -->
