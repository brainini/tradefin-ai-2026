# 5일차 프롬프트 — 실습 D(수업판) 독촉 메일 대작전

실습 D '독촉 메일 대작전 — 환율 타일 + AI 초안 승인 대기열'에서 쓰는 프롬프트입니다. 실습 쪽의 단계 번호(실습 D-1 · 01 …)와 맞춰 두었습니다. 복사 버튼 :material-content-copy: 으로 통째로 복사해 **웹 저장소**(`tradefin-web-T{조}-{번호}`) 창의 Claude Code 입력창에 붙여 넣습니다. 바꿀 자리는 `{중괄호}`이고, 중괄호 기호도 지웁니다.

- 프롬프트마다 첫 줄은 **목적**(지금 무엇을 위해 하는지), 다음 줄은 **할 일**입니다. 환율 타일 규칙 · 표 설계 · 초안 로봇 · 가드레일 G1–G7 · 승인 규칙 · 커밋 규칙처럼 긴 내용은 **작업 안내서** `guide/day5_lab_d.md`에 절마다 적어 두었고, 프롬프트는 '「1. 환율 타일」대로'처럼 그 절을 가리킵니다. 안내서는 열어 읽어도 됩니다(고치지는 않습니다 — 새 판은 `npm run guide:update`).
- AI 엔진(`claude -p`)으로 초안을 쓰는 진짜 실행 `npm run drafts`는 **내가** 터미널에서 합니다. AI는 `--dry-run`으로만 시험합니다.
- AI는 답 끝에 '확인할 것' 3줄을 보여 줍니다. 그 3줄을 실습 쪽의 '확인할 것'과 견줍니다.

| 부 · 단계 | 프롬프트 |
|---|---|
| 1부 · 같이 따라 하기(D-1 · 01 – 03) | [d1 환율 타일](#d1) · [d2 표 · 초안 로봇(Plan)](#d2) · [d3 승인 대기열 · 감사 기록](#d3) · [세이브 포인트(커밋)](#d-commit) |

## 자유 퀘스트 — 열린 프롬프트 {#d-free}

**도구** Claude Code · **실습 D-2 · 02** · 결과 내가 고른 방향으로 자란 관제탑 · 안내서 「7. 자유 퀘스트」

<!-- --8<-- [start:d-free] -->
```text
목적: 1부에서 만든 내 독촉 관제탑을 내 마음대로 키운다 — {하고 싶은 것 한 줄 · 몰라도 됨}
@guide/day5_lab_d.md 의 「7. 자유 퀘스트」대로 — 재미있는 방향 3개를 먼저 제안해 줘.
```
<!-- --8<-- [end:d-free] -->

**빈칸** `{하고 싶은 것 한 줄 · 몰라도 됨}` — 실습 쪽의 씨앗 한 줄을 그대로 넣어도 되고, '몰라도 됨'이라고만 써도 됩니다. AI가 방향 3개를 '와!' 한 줄씩과 함께 먼저 보여 줍니다 → 하나를 고르거나 고쳐서 답하면 계획 3줄 → 승인하면 만듭니다.

## 숫자가 다를 때 {#d-check}

**도구** Claude Code · 실습 쪽의 '확인할 것'과 내 숫자가 다를 때 · 안내서 「10. 숫자가 다를 때」

<!-- --8<-- [start:d-check] -->
```text
목적: 내 숫자가 실습 쪽의 값과 다른 까닭을, 고치기 전에 먼저 찾는다.
{항목}이 {기대값}이어야 하는데 내 결과는 {내 값}이야. @guide/day5_lab_d.md 의 「10. 숫자가 다를 때」대로 원인 후보와 확인 방법만 알려 줘.
```
<!-- --8<-- [end:d-check] -->

`{항목}` · `{기대값}` · `{내 값}`을 바꿔 보냅니다. 예: `대기 목록`이 `B022 · B041 · B104 · B066`이어야 하는데 내 결과는 `B022 · B041 · B066 · B104`.

**도구** claude.ai · Claude Code를 못 쓸 때 첫 메시지 · 안내서 「11. 채팅 경로」

<!-- --8<-- [start:d-chat] -->
```text
목적: Claude Code 없이 claude.ai 대화로 환율 타일을 만든다(초안 JSON도 가능).
첨부한 작업 안내서 day5_lab_d.md의 「11. 채팅 경로」대로 한다. @경로는 첨부 파일로 읽고, 바꾼 파일은 전체 내용을 파일 이름과 함께 보여 줘.
```
<!-- --8<-- [end:d-chat] -->

첨부: `guide/day5_lab_d.md` · `data/fx_fallback.json` · `data/README.md` · `app/page.tsx` · `lib/metrics.ts` · `lib/format.ts`(초안 JSON까지 하려면 `data/dunning_templates.md` · `data/tone_matrix.csv` · `--dry-run` 출력 전체(두 줄 + 대상 목록)도 — 받은 JSON은 VS Code 탐색기의 새 파일에 `workbench/drafts_chat.json`을 경로째 넣어 저장하면 폴더도 함께 생깁니다). 이 첫 메시지 다음에는 d1을 그대로 보냅니다.
