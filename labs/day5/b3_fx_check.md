# 환율 타일 검산표 — 기준일 2026-09-30 (실습 B3)

> **완성본 · 비교용.** Claude Code가 만든 '원화 환산(오늘 환율)' 타일의 숫자를 **손계산 없이** 견주는 기준입니다. 정답지가 아니라 검산표입니다 — 다르면 어디서 갈렸는지 찾는 것이 과제입니다.
> **어떻게 만들었나** 기본 원장 `data/checkpoints/d5_start.csv`(300건)를 앱과 같은 정제(`app/core/clean.py`)로 읽어 통화별 미결 잔액(`open_amount_ccy`)을 더하고, 환율 API `https://api.frankfurter.dev/v2/rates?base=USD&quotes=KRW,EUR,JPY,CNY&date=2026-09-30`의 응답으로 통화 1단위당 원화를 구해 곱했습니다. 시연 1(오전)의 결과 화면과 같은 숫자입니다. 기준일 환율은 지난 날짜라 바뀌지 않습니다 — **오늘 값만** 날마다 다릅니다.

- 합계는 반올림 전 값을 더한 것이라 통화별 칸을 더한 값과 끝자리 1원이 다를 수 있습니다.

## 2. 내 타일과 견주는 법

1. **기준일 계산이 맞았나** — 타일의 `오늘 총액 − 증감(원)`이 **5,788,865,573원(약 57.89억)**이면 기준일 쪽 계산이 맞습니다.
2. **증감 %** = 증감(원) ÷ 5,788,865,573 × 100. 오늘 환율이 9/30보다 낮으면(원화 강세) 마이너스입니다.
3. **±2% 경고선** — 오늘 총액이 5,673,088,262원(56.73억) 미만이거나 5,904,642,885원(59.05억)을 넘을 때만 '환율 변동 경고' 줄이 보여야 합니다.
4. 통화별로 다르면: JPY를 100엔당 환율 그대로 곱했나(100배 커진다) · EUR · CNY를 USD로 취급했나 · 기준일 환율을 `&date=2026-09-30`으로 받았나.
