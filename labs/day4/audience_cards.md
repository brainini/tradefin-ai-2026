# 독자 카드 3종 — 같은 숫자, 읽는 사람에 따라 다른 모양 (실습 B ③)

카드 한 장을 고릅니다. 숫자는 **코드가 만든 값**(경보 엔진의 결과 · 지표 JSON)이고, 문장과 모양만 독자에 맞춰 바뀝니다. 어느 카드든 같은 규칙을 지킵니다 — 입력에 없는 숫자를 쓰지 않는다 · 조치는 "권고(사람 승인 전)" · 숫자는 대조한다 · 확정은 사람이 한다.

| 카드 | 독자 | 읽는 시간 | 만드는 것 | 만드는 도구 |
|---|---|---|---|---|
| ① 경영진 Word 2쪽 | 대표 · 임원 | 3분 | 요약 3줄 · 포트폴리오 · 주의 바이어 5곳 · 한도 재배정 · 시나리오 · 경보 · 결정 요청 표(승인 주체) · 가정과 한계 | 해석 프롬프트(Claude · ChatGPT) → `make_report.py`(Word 템플릿) → `check_numbers.py` |
| ② 영업팀 바이어별 조치표 | 영업 담당자 | 1분(자기 바이어만 찾아 본다) | 엑셀 표 — 바이어 · 단계 · 조치 · 담당 · 기한, 등급별 조건부 서식 | Claude Code(`alerts.csv` → `openpyxl`) |
| ③ 대표 보고 메일 5줄 | 대표(모바일) | 30초 | 텍스트 5줄 — ① 한 줄 결론 ② 가장 큰 위험 숫자 ③ 이미 자동으로 한 일 ④ 결정해 달라는 것 ⑤ 다음 확인 시각 | Claude 또는 ChatGPT(지표 JSON을 붙여 넣기) |

## 카드 ① 경영진 Word 2쪽 — 제공 스크립트로

1. 입력: `data/checkpoints/d4_report_input.json`(15:00 공개 · 작업 사본은 `workbench/day4/data/`). 칸 이름은 `labs/day4/report_schema.json`이 정합니다.
2. 새 대화(Claude 또는 ChatGPT)에 **해석 프롬프트 B2**와 지표 JSON 전문을 붙여 넣어 JSON 하나를 받아 `workbench/day4/outputs/narrative.json`으로 저장합니다(코드 블록 표시 ```는 빼고 `{`로 시작하게).
3. `uv add docxtpl`(처음 한 번) → `uv run python labs/day4/make_report.py` → `workbench/day4/outputs/credit_report_2026-09.docx`.
4. `uv run python labs/day4/check_numbers.py` → 불일치 0이어야 다음 단계로.

## 카드 ② 영업팀 바이어별 조치표 — 엑셀

- 입력: 내 경보 엔진의 결과 `workbench/day4/outputs/alerts.csv` · `alert_summary.json`.
- 열: 바이어(buyer_id) · 단계(D-3 · D+7 · D+15 · D+30 · 선적 보류) · 조치(권고 문장) · 담당(영업 담당 / 채권관리팀장 / 대표) · 기한(다음 행동 날짜) · 등급(P1–P4). 등급이 높을수록 위에, P1은 빨강 · P2는 주황 칸 서식.
- 담당과 기한은 AI가 지어내지 않게 규칙을 준다 — 단계 사다리(D-3 · D+7 → 담당자 승인 / D+15 → 영업 담당 참조 / D+30 → 팀장 결정 / 통지 기한 → 대표 결재)와 '기한 = 기준일 + 며칠'을 프롬프트에 적는다.
- 확인: 행 수 = `alerts.csv`의 선적 보류 바이어 수와 같은가 · 엑셀을 열어 서식이 적용됐는가.

## 카드 ③ 대표 보고 메일 5줄 — 텍스트

- 입력: 지표 JSON 전문(입력에 있는 숫자만 쓰게 한다).
- 형식: ① 결론 한 줄 ② 가장 큰 위험 숫자 하나(단위와 기준일 포함) ③ 이미 한 일(자동 경보 · 이슈 링크) ④ 결정 요청 하나(승인 주체와 "권고(사람 승인 전)") ⑤ 다음 확인 시각. 줄마다 한 문장, 전부 합쳐 5줄.
- 확인: 메일 속 숫자마다 지표 JSON의 위치를 한 줄씩 찾아 적는다(`check_numbers.py`에 넣으려면 같은 모양의 `narrative.json`으로 만들어야 하니, 오늘은 손으로 대조해도 된다).

같은 폴더의 `prompts.md`에 있습니다 — 카드 ①의 해석 프롬프트는 **B2**, 카드 ② · ③의 시작 프롬프트는 **B3**, 레드팀은 **B4**입니다.
