# 4일차 프롬프트 — 실습 C(수업판)

실습 C '메일함 아침 당번 로봇'에서 쓰는 프롬프트입니다. 실습 쪽의 단계 번호(실습 C-1 · 01 …)와 맞춰 두었습니다. 복사 버튼 :material-content-copy: 으로 통째로 복사해 Claude Code 입력창에 붙여 넣습니다. 바꿀 자리는 `{중괄호}`이고, 중괄호 기호도 지웁니다.

- 프롬프트마다 첫 줄은 **목적**(지금 무엇을 위해 하는지), 다음 줄은 **할 일**입니다. 파일 이름 · 헤더 검사 · AI에게 주는 글 · 점수 · 보드 · 장부 · 커밋 규칙처럼 긴 내용은 **작업 안내서** `labs/day4/lab-c/lab_c_guide.md`에 절마다 적어 두었고, 프롬프트는 '「2. 로봇 v1」대로'처럼 그 절을 가리킵니다. 안내서는 열어 읽어도 됩니다(고치지는 않습니다).
- 입력은 `labs/day4/mail/` · `labs/day4/lab-c/` · `labs/day4/fraud_signals.md`(읽기만), 코드는 `scripts/`, 결과는 `workbench/day4/outputs/`입니다. 로봇은 명령 한 줄 `uv run python scripts/mail_bot.py`로 돕니다.
- **AI 엔진이 도는 실행은 내가 터미널에서 합니다.** Claude Code는 `--no-ai`로만 시험합니다 — 결과는 `workbench/day4/outputs/no_ai/`에 따로 생깁니다.
- AI는 답 끝에 '확인할 것' 3줄을 보여 줍니다. 그 3줄을 실습 쪽의 '확인할 것'과 견줍니다.

<!-- --8<-- [start:c-free] -->
```text
목적: 내 메일 당번 로봇을 내 마음대로 키운다 — {하고 싶은 것 한 줄 · 몰라도 됨}

```
<!-- --8<-- [end:c-free] -->

`{…}`에는 하고 싶은 것을 한 줄로 씁니다(예: `게임으로 만들고 싶다` · `팀장님이 덜 걱정하시게` · `몰라도 됨`). 실습 쪽의 '씨앗' 한 줄을 그대로 붙여도 됩니다. AI가 방향 3개를 내면 하나를 고르거나 고쳐서 답하고, 계획 3줄을 읽은 뒤 "좋아, 만들어"라고 보냅니다.

<!-- --8<-- [start:c-wow] -->

@labs/day4/lab-c/lab_c_guide.md 의 「7. 자유 퀘스트」대로 — 지금 결과로 할 수 있는 가장 놀라운 것 3가지를 제안해 줘.

## 안 맞을 때 — 어디서 갈렸나 {#c-mismatch}

**도구** Claude Code · 실습 쪽의 '확인할 것'과 내 결과가 다를 때 · 안내서 「10. 숫자가 다를 때」

<!-- --8<-- [start:c-mismatch] -->
```text
목적: 내 숫자가 기대와 다른 까닭을, 고치기 전에 먼저 찾는다.
기대는 {항목}이 {기대값}인데 내 결과는 {내 값}이야. @labs/day4/lab-c/lab_c_guide.md 의 「10. 숫자가 다를 때」대로 원인 후보와 확인 방법만 알려 줘.
```
<!-- --8<-- [end:c-mismatch] -->

`{항목}` · `{기대값}` · `{내 값}`을 바꿔 보냅니다 — 기대값은 실습 쪽의 '확인할 것'에서 옮겨 적습니다. AI가 `--no-ai`로 규칙 몫부터 다시 보여 줍니다.
