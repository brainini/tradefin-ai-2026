| 쓰는 도구 | 어디서 | 이 페이지의 프롬프트 |
|---|---|---|
| **Claude Code** (VS Code 확장) | 내 저장소를 연 VS Code | [A0](#a0) · [A1](#a1) · [A2](#a2) · [B1](#b1) · [B2](#b2) · [B3](#b3) · [B4](#b4) · [B5](#b5) |

!!! info "'outputs 폴더'는 어디인가"
    프롬프트에 나오는 **outputs 폴더**는 이 저장소에서 `workbench/day1/outputs/`입니다(저장소의 `CLAUDE.md`에 적혀 있고, Claude Code가 먼저 읽습니다). 노트북은 `workbench/day1/notebooks/`, 차트 PNG는 `workbench/day1/outputs/charts/`에 둡니다. 경로를 정확히 쓰고 싶으면 프롬프트의 "outputs 폴더"를 `workbench/day1/outputs/`로 바꿔 써도 됩니다.

!!! tip "'@'로 파일 지정하기"
    입력창에 `@` 뒤에 파일 이름 일부만 쳐도 후보가 뜹니다(예: `@halden`). 목록에서 고르면 `@data/day1/reports/halden_fictional_annual_report.md`처럼 경로가 들어갑니다. 이 페이지의 프롬프트에는 경로를 풀어 적었습니다.

## 프롬프트를 쓰는 습관 {#habits}

1. **근거를 함께 요구한다** — 인용은 원문 그대로 + 위치, 숫자는 공식 + 대입한 값 + 계산 코드.
2. **받은 뒤 확인한다** — 인용은 원문에서 ++ctrl+f++ 로 찾고, 숫자는 코드로 다시 계산한 값과 맞춘다.
3. **틀린 곳만 짚어 되묻는다** — 처음부터 다시 시키지 않고 "3번 행 인용이 원문에 없다, 그 행만 다시"처럼 말한다.
4. **잘 된 프롬프트는 저장한다** — `workbench/day1/prompts/`에 이름 + 판 번호로(예: `A1_위험신호_v2.md`) 두고, 고칠 때마다 커밋합니다. 프롬프트도 코드처럼 이력을 남깁니다.
5. **허락 창은 읽고 승인한다** — Claude Code가 파일을 바꾸거나 명령을 실행하기 전에 묻습니다. 무엇을 · 어디에 · 지우는지 세 가지를 읽고 `1 Yes`를 누릅니다. 파일 삭제 · 강제 push · `git reset --hard` 같은 명령은 거절합니다.

## A0 · CLAUDE.md에 내 규칙 더하기 {#a0}

**도구** Claude Code · **실습 A-1 ④** · 결과 `CLAUDE.md`(커밋 대상)

저장소에는 `CLAUDE.md`가 **이미 들어 있습니다.** 새로 만들지 않고 열어서 읽은 뒤, 내 업무에 맞는 규칙 한두 줄을 더합니다. 빈 프로젝트에서 처음 만들 때만 `/init`으로 초안을 받습니다.

<!-- --8<-- [start:a0] -->
```text
@CLAUDE.md 를 읽고, '일하는 방식' 맨 아래에 내 업무 규칙 두 줄을 더해 줘.
- {내 규칙 ①}
- {내 규칙 ②}
다른 줄은 고치지 마. 바뀔 내용(diff)을 먼저 보여 줘.
```
<!-- --8<-- [end:a0] -->

**규칙 예**(그대로 써도 됩니다 — 회사 이름 · 실명 · 실제 숫자는 쓰지 않습니다. 이 저장소는 공개입니다)

- 숫자에는 기준일과 통화(또는 단위)를 함께 쓴다.
- 외국어 문서의 인용은 원문 그대로 두고 번역은 따로 쓴다.
- 메일은 초안 파일로만 만들고 보내지 않는다.
- 추정한 값에는 '추정'이라고 표시한다.

**확인** 허락 창 오른쪽의 diff에서 **내가 더한 줄만** 바뀌는지 봅니다. 다른 줄이 바뀌면 `2 No`로 거절하고 "다른 줄은 고치지 마"를 다시 말합니다.

## A1 · 위험 신호 표 {#a1}

**도구** Claude Code(모드 Manual) · **실습 A-2 ⑥** · 결과 `workbench/day1/outputs/d1_signals_{회사}.md`

<!-- --8<-- [start:a1] -->
```text
@{파일} 을 읽고 대금 지급 위험 신호를 찾아라.
<역할> 수출기업 신용관리 분석가 </역할>
<맥락> 이 바이어에게 60일 외상(O/A)으로 수출한다. 결정은 사람이 한다. </맥락>
<과제> 체크리스트 8개 유형(계속기업 불확실성 · 유동성 부족 · 차입 약정 위반 · 차입 만기 ·
매출 감소·영업손실 · 자본잠식 · 결제조건 변경 · 구조조정)을 하나씩 점검하라. </과제>
<형식> 위험 신호 표: 신호 | 원문 인용 | 위치 | 심각도(상/중/하) + 안심 요소 표 + 세 줄 요약 </형식>
<제약> 인용은 원문 그대로. 찾지 못한 유형은 '명시되지 않음' </제약>
결과는 outputs 폴더에 d1_signals_{회사}.md 로 저장해.
```
<!-- --8<-- [end:a1] -->

**빈칸** `{파일}` · `{회사}` — [빈칸 값 표](#values)(Halden은 `halden`).

**어떻게 생겼나** 오전 시연 2의 6요소 프롬프트를 Claude Code용으로 바꾼 것입니다. 맨 앞의 `@파일`이 읽을 문서를 가리키고, 맨 끝 줄이 결과를 파일로 저장하게 합니다. 체크리스트 8개 유형 덕분에 **찾지 못한 유형도 '명시되지 않음'으로 표에 남습니다** — 없다는 것도 정보입니다. 위험을 줄이는 사실(안심 요소)은 위험 신호 표가 아니라 안심 요소 표에 따로 받습니다.

**확인할 것**

- 표의 **원문 인용 2개**를 골라 보고서 파일에서 ++ctrl+f++ 로 찾습니다. 글자 그대로 있으면 **일치**, 없으면 **불일치**입니다.
- 안심 요소로 나온 것이 위험 신호 표에도 들어가 있지 않은지 봅니다.
- 위치(쪽 · 절 번호)가 실제 위치와 맞는지 봅니다.

### A1 재질문 — 인용이 원문에 없을 때 {#a1-retry}

<!-- --8<-- [start:a1-retry] -->
```text
표의 {N}번 행 인용을 원문에서 찾지 못했다. 원문 문장을 글자 그대로 다시 인용하고, 없으면 '명시되지 않음'으로 바꿔라.
```
<!-- --8<-- [end:a1-retry] -->

`{N}`은 표에서 찾지 못한 행 번호입니다. **그 행만** 다시 시킵니다.

## A2 · 재무비율 계산 — 코드로 {#a2}

**도구** Claude Code(Manual) · **실습 A-2 ⑧** · 결과 `workbench/day1/outputs/d1_ratios_{회사}.md` + 코드 `scripts/ratios_{회사}.py`

<!-- --8<-- [start:a2] -->
```text
@{파일} 의 재무표로 4개 비율을 계산해 줘.
- 유동비율 = 유동자산 ÷ 유동부채, 부채비율 = 총부채 ÷ 자기자본, DSO = 매출채권 ÷ 매출 × 기간 일수, 영업이익률 = 영업이익 ÷ 매출
- 표: 비율 | 공식 | 대입한 숫자(원문 위치) | 결과 | 해석 한 줄
- 계산은 scripts/ratios_{회사}.py 로 하고 코드를 남겨. 기간이 1년이 아니면 일수를 바꿔.
- 결과는 outputs 폴더에 d1_ratios_{회사}.md 로 저장해.
```
<!-- --8<-- [end:a2] -->

**확인할 것**

- 대입한 숫자가 **재무표 어느 줄 · 어느 열**에서 왔는지 적혀 있고, 그 열이 **당기**(비교 연도가 아님)인지 봅니다.
- 재무표의 **단위**(천 · 백만)와 **기간**(연간 · 분기)을 밝혔는지 봅니다. 분기 보고서에 365일을 곱하면 DSO가 약 4배로 부풀려집니다.
- 숫자가 AI의 암산이 아니라 **스크립트가 낸 값**인지 봅니다(`scripts/ratios_{회사}.py`를 열어 보세요).
- 자본이 0 이하(자본잠식)이면 부채비율은 '해석 불가'로 표시해야 합니다.

**허락 창** Claude가 노트북을 만들고 실행할 때마다 창이 뜹니다. **실행 명령의 허락 창**이면 명령을 읽고 `1 Yes`, 확장 버전에 따라 **셀마다 Execute 창**이 뜨면 셀 코드를 읽고 Execute를 누릅니다.

**확인할 것**

- 차트의 한글이 네모로 깨지지 않는지, 해석 3줄이 **차트와 맞는지**(AI가 쓴 해석도 차트와 대조합니다) 봅니다.

## 채팅 경로 — Claude Code를 못 쓸 때 {#chat-path}

Claude Code 계정이 없거나(무료 플랜은 쓸 수 없습니다) 확장이 로그인되지 않으면, **claude.ai 또는 ChatGPT**에 파일을 올려 같은 일을 합니다. 프롬프트는 같고, 아래 세 가지만 바꿉니다.

| 바꿀 곳 | 어떻게 |
|---|---|
| `@파일` 줄 | 지웁니다. 대신 **파일을 첨부**합니다(보고서 `.md` · `d1_buyers_raw.xlsx` 또는 `.csv`). ChatGPT 무료는 하루 업로드 수가 적으니 Claude를 먼저 권합니다 |
| "결과는 outputs 폴더에 … 저장해" 줄 | 지우고 **"결과는 Markdown 표로 보여 줘"**로 바꿉니다. 받은 표를 내가 복사해 VS Code나 메모장에서 같은 이름의 파일로 저장합니다 |
| 코드 파일(`scripts/…`)과 노트북 | A2는 "계산 코드를 답에 보여 줘", B4는 "노트북 대신 **코드를 실행해 차트 PNG 3개**를 만들어 내려받게 해 줘"로 바꿉니다 |

만든 파일은 GitHub 웹 화면(**Add file → Upload files**)으로 `workbench/day1/outputs/`에 올리고 커밋 메시지는 '무엇' · 빈 줄 · '왜'로 씁니다. 자세한 순서는 [실습 A의 채팅 경로](../day1/lab-a.md#chat-path)에 있습니다.

    이 프롬프트는 가상(합성) 데이터와 공개 공시용입니다. 회사 실데이터는 익명화한 것이라도 올리지 않습니다. 쓰는 AI의 '모델 개선(학습)' 설정은 끄고 시작합니다.
