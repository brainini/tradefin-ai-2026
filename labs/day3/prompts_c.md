# 3일차 프롬프트 — 실습 C

실습 C '한빛식당 식수 예보'에서 쓰는 프롬프트입니다. 실습 쪽의 단계 번호(실습 C-1 · 01 …)와 맞춰 두었습니다. 복사 버튼 :material-content-copy: 으로 통째로 복사해 Claude Code 입력창에 붙여 넣습니다. 바꿀 자리는 `{중괄호}`이고, 중괄호 기호도 지웁니다.

- 프롬프트마다 첫 줄은 **목적**(지금 무엇을 위해 하는지), 다음 줄은 **할 일**입니다. 정제 규칙 · 판정 기준 · 예보관 설정 · 페이지 규칙 · 커밋 규칙처럼 긴 내용은 **작업 안내서** `labs/day3/lab-c/lab_c_guide.md`에 절마다 적어 두었고, 프롬프트는 '「4. 정제 규칙」대로'처럼 그 절을 가리킵니다. 안내서는 열어 읽어도 됩니다(고치지는 않습니다).
- 입력은 `labs/day3/lab-c/`의 세 파일(읽기만), 결과는 `workbench/day3/outputs/`(이 저장소의 'outputs 폴더'), 코드는 `scripts/`에 둡니다. 페이지 `hanbit_lunch.html`은 스크립트 `scripts/lunch_page.py`가 계산해서 씁니다 — 같은 입력이면 같은 페이지가 나옵니다.
- AI는 답 끝에 '확인할 것' 3줄을 보여 줍니다. 그 3줄을 실습 쪽의 '확인할 것'과 견줍니다.

<!-- --8<-- [start:c3] -->
