# 6일차 프롬프트 — 수업판 해커톤 '오늘의 퀘스트는 내가 만든다'

자유 주제 개인 해커톤에서 쓰는 프롬프트입니다. 해커톤 쪽의 단계 번호(H0–H7)와 맞춰 두었습니다. 복사 버튼 :material-content-copy: 으로 통째로 복사해 Claude Code 입력창에 붙여 넣습니다. 바꿀 자리는 `{중괄호}`이고, 중괄호 기호도 지웁니다.

- 프롬프트마다 첫 줄은 **목적**, 다음 줄은 **할 일**입니다. 오늘은 사람마다 만드는 것이 달라서 작업 안내서 `guide/day6_hackathon.md`(내 해커톤 저장소 안)에는 사양 대신 **지킬 선**(MVP 크기 · 가상 데이터 · 비밀 · 빌드 통과)과 일하는 순서만 있습니다. 무엇을 만들지는 내가 정합니다.
- 내가 쓰는 파일은 저장소 맨 위의 `SPEC.md` · `README.md` · `DEMO.md`와 앱 폴더(`app/` · `components/` · `lib/` · `data/`)입니다. `hackathon/`의 양식과 `guide/`는 읽기만 합니다.
- AI는 답 끝에 '확인할 것' 3줄을 보여 줍니다. 그 3줄대로 **운영 주소**에서 눌러 봅니다.
